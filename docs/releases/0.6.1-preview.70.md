# v0.6.1-preview.70

**日期**：2026-11-14
**类型**：pre-release
**对应里程碑**：P5 终端（issue #63）+ 编辑器保存冲突检测（issue #24）

### 亮点

- **内置终端（本地 + SSH，P5 #63）**：
  - **会话活在 Rust 侧**（app 级 State）：窗口销毁/重建不中断，256 KiB 环形
    滚动缓冲，重开面板/重连后经 `pty_replay` 恢复屏幕；
  - 统一抽象：本地 shell（Windows pwsh7 → powershell.exe → cmd；Unix
    `$SHELL`/bash -l）与 SSH（系统 `ssh` 二进制在 pty 内启动，
    `TERM=xterm-256color`，主机密钥/密码交互走 ssh 自身提示）同一会话模型；
  - **非用户关闭的退出自动重连一次**（同参数重建 + 缓冲重放），再退落
    `closed`；用户关闭不重连；应用退出 `kill_all` 全量回收；
  - xterm.js 多会话面板：标签切换/关闭、`+ 本地` / `+ SSH`（host/user/port
    校验）、FitAddon 自适应 + resize 转发、明暗/插件主题 token、中英 i18n；
  - 桌面 6 命令（`pty_open/write/resize/close/list/replay`）+ `pty:data/
    state/exit` 三通道（base64 无损字节流）。
- **编辑器保存前外部修改冲突检测（#24）**：写盘前读取磁盘内容与
  `savedContent` 基线比对——外部已修改 → 「覆盖保存 / 重新加载磁盘内容 /
  取消」三选；文件被删 → 提示保存即重建；读取失败 → 明确询问；浏览器 dev
  不做判定。

### 修复

- pty 事件载荷缺 `type` 导致 web 守卫整帧丢弃（xterm 收不到任何输出、
  PowerShell 卡在 DSR 应答）——按订阅通道注入类型并加回归测试；
- 保存冲突快照误读 `FileContentResult.text`（此前恒空串，重载会清空缓冲）。

### 验证

- workspace **828**（含 `lc-core::pty` 26 项：缓冲上限/重连一次语义/事件
  顺序/close 幂等/回收/ssh 参数构造）、web **677**、ext-host 21 全绿；
  fmt/clippy/vue-tsc/lint 零告警；远端 CI 与 webview-e2e 双绿。
- **桌面运行时 e2e**：新建本地会话 → PowerShell 提示符 → 真实输入管线键入
  `echo lc-terminal-e2e` → 回显与输出经 replay 缓冲读回；外部改盘 → Ctrl+S
  → 冲突弹层 → 重新加载 → 缓冲内容=磁盘且 dirty 清零。

### 已知限制

- SSH 依赖系统 `ssh` 客户端（不捆绑）；主机密钥首次确认在终端内交互。
- 终端会话不跨应用重启持久化（窗口重建不中断，进程退出即回收）。
- Unix 下孙进程回收依赖 pty 常规语义（与既有 process lane 的 Job Object v1
  限制同级接受）。

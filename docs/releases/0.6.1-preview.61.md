# v0.6.1-preview.61

**日期**：2026-11-10
**类型**：pre-release
**对应里程碑**：P6 稳定化（鸿蒙历史命令补齐与迁移）

### 亮点

- 鸿蒙历史补齐：`history_rename`/`history_archive` 原生命令（锁定标题不被
  后续保存覆盖）；localStorage 历史一次性幂等迁移到原生落盘。

### 新增

- `crates/lc-ohos/src/history.rs`：`rename`/`archive`（共享 mutate；title
  trim、拒空/超 120 字，与桌面一致；rename 写 `titleLocked: true`）；
  `history_save` 增加 `merge_metadata`，后续轮次保存不覆盖锁定标题与归档态。
- `apps/web/src/ohos/tauriShim.ts`：rename/archive 走原生优先；一次性迁移——
  检测到 `lite-code.ohos.history` 逐条 `history_save` 后清 key，失败保留
  下次重试，共享迁移 Promise 去重，全部成功才清理；日志前缀 `[ohos-history]`。
- `history_migrate_workspace` 确认无鸿蒙调用点，保持 localStorage 并注释。
- demo 版本号同步 .61。

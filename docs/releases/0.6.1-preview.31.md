# v0.6.1-preview.31

> Agent 全宽模式支持 Ctrl+F 在对话中查找：匹配消息正文与思考内容，逐条跳转并高亮。

## 新增

- **Ctrl+F 会话内查找**：仅在 Agent 全宽模式拦截，编辑器/停靠侧栏的 Ctrl+F 不受影响。
- 查找条包含输入框、`当前/总数`、上一个、下一个与关闭按钮；Enter / Shift+Enter 循环跳转，
  Escape 关闭并清空查询。
- 匹配范围为消息 `text` 与 `thinking`，大小写不敏感、按子串匹配；空查询显示「无匹配」。
- 命中消息滚动到视口中央，并以强调色描边高亮当前消息；切换会话时自动关闭查找条。
- 纯函数 `findMessageMatches` / `cycleFindIndex` 独立可测。

## 验证

- Web：lint / typecheck / `pnpm test`（396 项 / 27 文件）/ build 全绿；
  新增 agentFind 3 项（大小写/思考内容、空查询、循环边界）。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）：
  - 注入 3 条消息（2 条含 `login`，其中 1 条只在 thinking 中），Ctrl+F 打开查找条；
  - 输入 `login` 显示 `1/2` 并高亮第 1 条；点击下一个变为 `2/2`、高亮第 2 条；
  - Escape 关闭查找条；刷新后注入会话已清除，应用回到空会话。

## 已知限制

- 高亮粒度是「整条消息」而非行内字符；不改变 Markdown 渲染结构，避免 v-html 重排。
- 不检索工具输出、审批卡、压缩记录与附件正文。
- 只在 Agent 全宽模式生效；编辑器侧栏中的 Agent 面板按 Ctrl+F 仍交给编辑器。

# v0.6.1-preview.18

> 双模式视觉重构：Agent 模式对齐 Kimi Code Desktop，编辑器模式对齐新版 VS Code。

## Agent 模式（参考 Kimi Code Desktop）

- **中性色板**：深色 `#141414 / #181818 / #1b1b1b`，浅色 `#f6f6f6 / #f0f0f0 / #ffffff`；
  强调色改为中性黑白，不再使用蓝色强调。
- **布局**：隐藏活动栏与状态栏，272px 侧栏 + 全宽对话；标题栏 38px，保留模式切换、菜单、
  命令中心与窗口控件。
- **侧栏**：项目/工作区分组展示，每组可展开/折叠，显示对话数、悬停新建聊天与移除；
  顶部搜索框按标题/模型过滤；底部「供应商 / 设置」入口。
- **对话区**：48px 顶栏、860px 居中内容列与 composer、14px 正文、12px 工具文本、
  历史会话提示条与每轮用量同样居中。
- **模式切换**：标题栏左侧 `<>` / Agent 双图标，切换后保持布局偏好。

## 编辑器模式（参考新版 VS Code）

- 活动栏 48px、图标 20px；活动项保留左侧强调条。
- 标签栏 34px，活动标签顶部强调线；关闭按钮仅悬停/活动时显示。
- 新增面包屑栏（最近 5 段路径），高度 24px。
- 面板标签 34px；标题栏模式切换与命令中心保持。
- 保留原有蓝色强调色与 VS Code 式侧栏、编辑器、右侧功能栏、状态栏。

## 参考源码

- Kimi Code Desktop（社区开源）：`apps/web/src/styles/tokens.css` 与 `App.tsx`
  的 Projects/Chats 侧栏、topbar、composer 结构。
- microsoft/vscode：`src/vs/workbench/browser/parts` 下活动栏、标题栏、状态栏与
  `src/vs/workbench/browser/parts/editor` 的标签/面包屑结构。

## 验证

- Web：lint / typecheck / `pnpm test`（360 项 / 22 文件）/ build 全绿。
- Rust 无变更，沿用 605 项基线。
- 真机（Windows Tauri dev）：
  - Agent 模式：工作区分组、搜索、线程切换、历史会话、每轮用量、居中 composer 在亮/暗主题检查通过。
  - 编辑器模式：48px 活动栏、34px 标签、活动标签强调线、面包屑、面板标签与状态栏检查通过。
  - 修复了 `:global()` 选择器写法导致样式误套到 `.shell`、窗口被压窄的问题。

## 已知限制

- 视觉与布局参考公开源码，不是像素级复刻；未引入 VS Code 扩展市场/键位系统或 Kimi 的
  quota、终端、预览等完整功能区。
- Agent 模式的设置/供应商入口会切回编辑器模式（设置页目前是编辑器标签）。
- 工具卡仍按本轮聚合展示，未按事件时间线穿插。

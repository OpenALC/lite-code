# v0.6.1-preview.69

**日期**：2026-11-14
**类型**：pre-release
**对应里程碑**：P6 稳定化（插件 Webview UI 协议整改 + iframe 沙箱双平台）

### 亮点

- **插件 Webview UI M2-R 协议整改**（`d854b15`）：
  - 稳定节 id（1–64 位 `[a-z0-9-]`、首字符字母、视图内唯一）替代数组序号，
    节重排/插入不串草稿与数据；
  - initialize 完整节描述 DTO 替代 `sectionKinds` 白名单——宿主按声明过滤列/
    约束动态值（≤500 行、≤64 kv 对、单串 16 KiB、总量 256 KiB）；
  - `source: "provider"` 替代虚设的 `valuesCommand`（回读从不调用命令 handler），
    旧声明明确报清单错误、不做猜测转换；
  - Web 侧同步代次 + 在途请求令牌 + 语义指纹：乱序响应只采最新、插件禁用/
    删除不写回、语义变更只重置该节、关闭视图清理草稿（password 不进持久化）。
- **插件 Webview UI M3 iframe 沙箱（§7 红线修订后显式 opt-in）**（`5779e0e`、
  `aad0106`）：
  - 清单 `contributes.ui.webviews`（entry+assets 白名单、洁净路径 fail-closed）；
  - `lc-plugin` 协议 handler：canonical 根内校验、仅 GET、Content-Type 闭集、
    `nosniff`、子文档 CSP 钉死视图资源前缀（Windows `http://lc-plugin.localhost`/
    Linux `lc-plugin://localhost` 双形状）；
  - 一次性 nonce 握手 + 专属 MessageChannel：错误 source/nonce/代次/重复握手/
    旧端口/跨插件命令全部拒绝；`getState/setState/postCommand` 三 op 闭集，
    bridge 状态 per-plugin（键 64/值 64 KiB/插件 256 KiB）落盘用户数据目录；
    重载/导航/禁用即关端口清 nonce；
  - EXTENSIONS §7 按批准文本修订：插件代码永不进主 webview 特权上下文，
    iframe 仅 sandbox=allow-scripts + 白名单桥；数据驱动仍是默认，iframe
    为清单显式 opt-in + 安装确认固定文案明示；
  - 运行时验证：Windows WebView2 全链（资产加载→握手→三 op→跨插件拒绝）；
    Linux WebKitGTK CI 自测（xvfb + `--webview-selftest`，
    run 43356165068）——**M3 双平台启用前提全部具备**。
- **UI：全局连续曲率圆角**（`f35d1a6`）：`corner-shape: squircle` 基线
  （不支持环境回落经典圆角），13 处真圆元素显式 `round` 退出。

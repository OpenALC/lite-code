# v0.6.1-preview.44

> 编辑器标签支持固定：固定标签排在最左，批量关闭时保留。

## 新增

- 标签右键菜单新增「固定标签 / 取消固定」。
- 固定标签排到固定组末尾并显示蓝色图钉；取消固定移到未固定组末尾。
- 固定状态随 `lite-code.tabs.v1` 持久化，重启后恢复。
- 批量关闭保护固定标签：
  - 「关闭其他」不关闭固定标签；
  - 「关闭右侧」跳过固定标签；
  - 「关闭已保存」只关闭未固定且干净的标签。
- 固定标签仍可通过 ×、中键或「关闭」单独关闭。

## 验证

- Web：lint / typecheck / `pnpm test`（408 项 / 28 文件）/ build 全绿；
  新增固定排序/批量关闭 2 项、持久化 1 项。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）：
  - 对 `index.html` 右键「固定标签」，标签移到首位并出现图钉；
  - 再次右键「取消固定」，图钉消失；
  - 测试后恢复标签顺序。

## 已知限制

- 固定数量没有上限，固定过多会压缩未固定标签空间。
- 取消固定后移到末尾，不恢复原位置。
- 固定/取消固定仅通过右键菜单，暂未分配快捷键。

# v0.6.1-preview.40

> Problems 面板支持按严重级筛选：全部 / 错误 / 警告，并显示各自数量。

## 新增

- 问题面板顶部新增筛选条：`全部 N`、`错误 N`、`警告 N`。
- 筛选只影响列表展示；页签徽标与状态栏 `⚠ N` 仍显示诊断总数。
- 筛选后无匹配时显示「当前筛选没有问题」，与「没有发现问题」区分。
- 新增 `filterProblems` 纯函数，`errors` 对应 severity 1、`warnings` 对应 severity 2。

## 验证

- Web：lint / typecheck / `pnpm test`（405 项 / 28 文件）/ build 全绿；
  lspDiagnostics 新增筛选 1 项（不修改源数组）。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）注入 2 error + 1 warning + 1 info：
  - 筛选条显示 `全部 4 | 错误 2 | 警告 1`；
  - 默认列表 4 行；点击「错误」2 行；点击「警告」1 行；再点「全部」恢复 4 行。

## 已知限制

- 只支持全部/错误/警告三档，不提供信息/提示筛选。
- 筛选状态不持久化，切换工作区或重启后回到「全部」。
- 列表仍按路径/行/列排序，不按严重级排序。

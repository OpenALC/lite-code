# v0.6.1-preview.63

**日期**：2026-11-10
**类型**：pre-release
**对应里程碑**：P6 稳定化（鸿蒙 UI 抛光）

### 亮点

- 鸿蒙供应商 sheet 支持系统返回键关闭 + Tab 焦点陷阱 + Escape；
  归档开关零计数不再显示「0」。

### 变更

- `Index.ets` `onBackPress()`：sheet 打开时经 `runJavaScript` 调
  `__lcOhosCloseSheet()` 并消费返回键；关闭时走系统默认（Ability 退后台）。
  页面 ↔ ArkTS 经 `javaScriptProxy` 新增 `setSheetOpen` 同步状态。
- `OhosApp.vue` + 新增 `ohos/sheet.ts`：打开聚焦首个可交互元素、Tab/Shift+Tab
  在 sheet 内循环、Escape 关闭、关闭后焦点回供应商按钮（纯函数 5 项单测）。
- `historyView.archiveToggleView`：0 计数显示固定「显示已归档」，有计数带 N
  （+2 单测）。
- 兼容性：新 ArkTS + 旧 Web 安全；新 Web + 旧 ArkTS 退化为按钮/Escape 关闭。

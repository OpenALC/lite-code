# v0.6.1-preview.15

> 修复 Agent 消息流在工具卡/审批卡较多时被压成细条、无法滚动的问题。

## 修复

- `.stream` 的直接子项统一 `flex: none`。此前 flex 子项默认 `flex-shrink: 1`，
  一轮里工具卡较多时会被压成十几像素高的细条，内容全部叠在一起。
- 流容器保持 `overflow-y: auto`；内容超出后正常滚动，并继续随新事件自动滚到底。

## 验证

- 真机打开一条 23 个子项的 Agent 会话：`scrollHeight 2950 / clientHeight 522`，
  工具卡恢复完整高度，滚动到底正常。
- Web：lint / typecheck / `pnpm test`（352 项 / 21 文件）/ build 全绿。
- Rust 无变更，沿用 preview.13 起的 601 项测试基线。

## 说明

- 本次只改 Agent 面板样式，不涉及会话、工具或 provider 行为。
- 若会话停留在审批卡，滚动与输入区不受影响；审批仍需手动选择。

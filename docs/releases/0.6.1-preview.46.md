# v0.6.1-preview.46

> 活动栏与常用工具图标批量换成 Kimi 风格的 24×24 填充路径。

## 变更

- 从 Kimi Code Desktop 资源包静态提取 91 个 `kimi-*` 图标（已与线上 DOM 路径校验一致）。
- 替换为 Kimi 图标的入口：活动栏「文件树」（folder-tree）、「任务」（节点图）、
  以及工具栏常用的 `plus / x / chevron / chevron-down / arrow-up / file / pencil /
  terminal / archive`，全部使用 `fill="currentColor"` 的 24×24 路径。
- 保留现有线性图标：`git`、`db`、`providers`、`extensions` 等暂无对应 Kimi 图标的入口。

## 验证

- Web：lint / typecheck / `pnpm test`（408 项 / 28 文件）全绿；纯图标路径替换，无新增测试。
- Rust：无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）：活动栏截图确认新图标渲染正常、风格统一。

## 已知限制

- `git` / `db` / `providers` / `extensions` 仍为自绘线性图标，与 Kimi 填充风格存在观感差异。
- 其余未替换的次级图标（sun/moon、history、code 等）维持现状。

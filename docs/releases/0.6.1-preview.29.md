# v0.6.1-preview.29

> 启用新应用 Logo：白色背景四角改为透明圆角，覆盖 Windows/macOS/Linux/Android/iOS
> 与 Web favicon。

## 新增

- 新图标母版：1254×1254 原图缩放为 1024×1024，以 225px 圆角蒙版裁切，
  四角 alpha=0，中心保持不透明。
- `tauri icon` 重新生成 `apps/desktop/src-tauri/icons/` 全套资产：
  Windows ICO、macOS ICNS、Linux PNG、Microsoft Store 方形图标、Android mipmap
  （含圆形与前景层）、iOS AppIcon 全尺寸。
- Web 端新增 `apps/web/public/favicon.png` 并在 `index.html` 声明 `<link rel="icon">`。
- `scripts/dev/icon-source.png` 同步替换为新的圆角母版，便于后续再生成。

## 验证

- 母版与输出检查：`128x128@2x.png`、`32x32.png`、`icon.png` 四角 alpha 均为 0，
  中心 alpha 为 255；`icon.ico` 含 256×256 帧，Chromium 可正常渲染。
- 强制重新链接 `lc-desktop.exe` 后，Shell 提取的 32×32 图标为蓝色新 Logo（不再是旧的黑底橙色图标）。
- Web：`favicon.png` 经 Vite dev server 返回 200（21.5 KB）。
- Web 门禁沿用 390 项 / 26 文件；Rust 608 项基线不变。

## 已知限制

- Windows 资源管理器/任务栏可能缓存旧图标，升级后需重启资源管理器或等待缓存刷新。
- 32×32 下 Logo 内的「Lite Code / OpenALC」文字不可读，仅保留终端窗口轮廓；
  已同时提供 16–256px 多尺寸帧供系统选择。
- Android 自适应图标背景仍为白色；如需品牌色背景需单独提供 foreground/background 图层。

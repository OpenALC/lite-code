# v0.6.1-preview.54

**日期**：2026-11-09
**类型**：pre-release
**对应里程碑**：P6 稳定化（Agent 统计修复）

### 亮点

- 修复 Agent 用量统计「一轮两行」：终态事件重复/迟到投递时按轮号覆盖而非追加，
  历史载入与在途轮次状态隔离。

### 修复

- 根因：`finalizeTurn` 对统计行纯追加（历史提交 `45aa637` 移除了按轮幂等替换）；
  上一轮迟到的 `usage + done` 在 UI 已开始下一轮后到达时产生幽灵行
  （`#2 120/40`），并把当前轮真正的 done 吞掉；`loadHistory` 未清理在途轮次
  累计器，旧会话迟到统计叠加到历史快照形成第二类双行。
- 修复（`apps/web/src/services/agentSession.ts`）：
  - `resetTurn` 记录当前用户轮号；`finalizeTurn` 按轮号 upsert（同轮 filter
    后插入并排序），重复 done/error 覆盖同一行。
  - 终态事件不再提前清空 usage 累计器与 `turnStartedAt`，后续真 done 补全同一行。
  - `loadHistory` 清空在途轮次状态；`resetSession`/`switchMode`/新会话同步清理。
- 新增 5 项单测（多 usage/多工具/重复 done 一行；迟到 done 不拆行；error+done
  一行；多轮每轮一行；历史载入后迟到 done 不追加）。

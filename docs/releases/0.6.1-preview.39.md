# v0.6.1-preview.39

> Ctrl+P 空查询面板加入工作区与历史会话入口，不再只有文件和命令。

## 新增

- 空查询排序调整为：
  1. 最近工作区（最多 2 个）
  2. 未归档历史会话（最多 2 个）
  3. 最近/打开的编辑器（最多 4 个）
  4. 最近命令（最多 2 个）
- 选择工作区：切换工作区并进入 Agent 模式。
- 选择会话：复用「快速打开恢复会话」链路，切换所属工作区并加载消息流。
- 归档会话不进入空查询列表；输入关键词时仍可搜索到并恢复。

## 验证

- Web：lint / typecheck / `pnpm test`（404 项 / 28 文件）/ build 全绿。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）空查询实际列表：
  - `tangshan`、`lite-code` 两个工作区；
  - 「继续，用一句话总结。」「用一句话说明这个项目是什么。」两个 tangshan 会话；
  - 4 个文件 + 「设置」「打开工作区…」2 个命令，共 10 项。

## 已知限制

- 工作区/会话各固定最多 2 条，总数 10 条封顶。
- 工作区按列表顺序，不按最近使用时间排序；会话按保存时间倒序。
- 归档会话不在空查询展示，需输入关键词检索。

# v0.6.1-preview.50

**日期**：2026-11-09
**类型**：pre-release
**对应里程碑**：P6 稳定化（鸿蒙首版外壳 MVP）

### 亮点

- 鸿蒙（HarmonyOS）首版「只读 + 对话」外壳 MVP：工程骨架、虚拟 origin 资源管线、
  只读前端、宿主 crate 全部落地，API 26 模拟器端到端验证通过。

### 新增

- `apps/ohos/`：HarmonyOS 产品工程（bundleName `dev.litecode.ohos`，phone/tablet/2in1，
  INTERNET 权限，signingConfigs 为空）；`Index.ets` 实现虚拟 origin
  （`https://app.litecode.example`）+ `onInterceptRequest` + 显式 MIME 表 +
  路径穿越防护 + 404 响应；dev 开关指向 `10.0.2.2:5173`。
- `scripts/ohos/build.mjs`：环境校验 → `build:ohos` → 产物校验（无 Monaco chunk）→
  rawfile 同步 → ohpm install → `hvigorw assembleHap` → 打印安装命令。
- `apps/web` ohos 专用 MPA 入口：`ohos.html` + `src/ohos/`（OhosApp 三视图只读壳、
  ReadonlyCodeView、tauriShim 命令白名单 + 事件回灌）；`build:ohos` 产物
  318 KiB（JS gzip 100 KiB），Monaco 不进构建图。
- `crates/lc-ohos`：鸿蒙宿主 crate（workspace 成员），`workspace_root` /
  `fs_read_dir` / `fs_read_file` 复用 lc-core 路径校验；`session_create` 强制 plan；
  stub agent（20 delta + done，可取消）；其余命令 `not_implemented`。
- `bridge.ts` 新增 `shellKind()` / `isReadOnly()`；`FileTree` 只读隐藏写操作；
  `AgentPanel` 支持 `forceMode` 锁定、附件仅 Tauri。

# v0.6.1-preview.22

> Agent 模式预览侧栏：输入本地 http(s) 地址，在右侧 rail 中直接查看页面。

## 新增

- Agent 头部新增预览按钮，与 Git 按钮共用右侧 rail（一次只显示一个）。
- 预览面板：
  - URL 输入，Enter/「加载」应用；缺协议自动补 `http://`。
  - 仅允许 `http(s)`；`javascript:` / `file:` / `data:` 等返回可读错误。
  - iframe 使用 `sandbox="allow-scripts allow-same-origin allow-forms allow-popups"` +
    `referrerpolicy="no-referrer"`。
  - 「刷新」重建 iframe；「清除」移除地址；最近一次合法地址写入 localStorage。
  - 关闭按钮或再次点击预览按钮收起 rail。
- 抽出 `normalizePreviewUrl` 纯函数并补 4 项单测（协议补全/非法协议/空值/非法 URL）。

## 验证

- Web：lint / typecheck / `pnpm test`（373 项 / 24 文件）/ build 全绿。
- Rust 无变更，沿用 607 项基线。
- 真机（Windows Tauri dev）：
  - 打开预览 rail，输入 `localhost:5173` 成功加载 iframe（测试时即应用自身页面）；
  - 输入 `javascript:alert(1)` 返回「仅支持 http(s) 地址」；
  - 关闭/清除后 localStorage 不残留地址。

## 已知限制

- 只有 URL 预览，不自动发现开发服务器端口，也不提供截图/设备尺寸切换。
- 外部页面受 CSP `frame-src http: https:` 与站点 `X-Frame-Options` 限制。
- 预览与当前工作区/对话没有自动绑定，地址是应用级记忆。

# v0.6.1-preview.16

> Agent 增加会话历史、活动状态、每轮 token 统计，并加入「编辑器 / Agent」双模式布局。

## 新增

- **会话历史**：每轮结束后把会话快照写入 `<data_dir>/agent-history/<sessionId>.json`；
  Agent 头部历史按钮/Agent 模式左侧栏列出标题、模式、模型与时间，可切换、删除。
  - 历史会话以只读视图打开，状态显示「历史会话」，过期审批自动清除。
  - 从历史发送会新建会话，并把最近 12 条消息（最多 12k 字符）作为上下文注入；
    新会话不受旧 Rust 会话生命周期影响。
- **活动状态**：头部显示 思考中 / 生成中 / 工作中 / 等待审批 / 已完成 / 出错 / 历史会话，
  思考、生成、工具执行期间带呼吸提示。
- **每轮 token**：每完成一轮记录输入、输出、缓存 token 与耗时，以「每轮用量」列表展示；
  usage 事件按 LLM 调用累加，上下文条仍使用最后一次请求的占用。
- **双模式**：活动栏顶部新增「编辑器 / Agent」切换。
  - 编辑器模式保留 VSC 式活动栏/侧栏/编辑器/右侧功能栏。
  - Agent 模式为会话列表 + 全宽 Agent 对话，点击资源管理器/搜索/Git/数据库会自动切回编辑器模式。
  - 模式写入 `localStorage`，重启后保持。

## 实现

- Tauri 新增 `history_list/load/save/delete`，文件 id 白名单、4 MiB 上限、Unix 0600。
- 会话快照落盘前截断单条工具输出到 20k 字符；历史载入做最小形状校验。
- 控制器新增 `status/turnStats/archived`，`loadHistory()` 与历史续聊上下文；
  历史视图允许重新选择模型/思考挡位。

## 验证

- Web：lint / typecheck / `pnpm test`（356 项 / 21 文件）/ build 全绿；新增状态/用量/历史续聊/桥接测试。
- Rust：新增 history 3 项测试（roundtrip、非法 id、非对象载荷）；全量结果见发布记录。

  - 历史列表/浮层在亮色、暗色下视觉检查通过。

## 已知限制

- 历史续聊是「上下文注入」而非恢复原会话；工具调用记录不会重新执行。
- 工具卡仍按本轮聚合展示，未按事件时间线穿插。
- 历史文件保存在本机数据目录，不加密；包含工具输出，请勿在共享账户下保存敏感内容。
- 模型/供应商仍以 `providers.json` 为准；历史里的模型若已删除，载入后回退到默认模型。

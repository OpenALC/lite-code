# v0.6.1-preview.68

**日期**：2026-11-11
**类型**：pre-release
**对应里程碑**：P6 稳定化（插件市场上线——搜索/安装/更新/卸载/签名/镜像全链路）

### 亮点

- **插件市场 M1-M3 全链路上线**（`docs/plans/plugin-marketplace.md`）：
  - **静态 index + 多源镜像**：registry 是带 sha256 的 JSON 索引（与
    updater-manifest 同构），任意 https/file URL 可加载；多源并行拉取、
    semver 最高去重、失败源不毒化结果（staleSources 提示）。
  - **原子安装**：下载→sha256→zip-slip 防穿越→清单一致性→tmp+rename+bak
    回滚→三级配额（64MiB 包/256MiB 解压/1GiB 总量）→GC 挂宿主启动。
  - **deps 自动安装**（M2）：同源优先/跨源兜底、深度 8、环检测复用
    Tarjan SCC、失败保留已装兄弟节点。
  - **签名强制档**（M3）：minisign-verify（MIT、零依赖、deny 通过），
    sha256 文本签名 + trusted comment 三重绑定防跨包挪用；未签名/异钥/
    注释哈希不符/换包改 index 全部拒绝；与 updater 签名分钥（爆炸半径隔离）。
  - **多镜像回退**：index 与包下载按镜像顺序回退，sha256 不符也换镜像
    （污染镜像不毒化安装）。
  - **浏览 UI**：ExtensionsPanel「浏览市场」tab——搜索/结果卡片/unsigned
    与 file 源徽标/安装确认对话框（§3.7 字段全覆盖：来源/permissions/
    signatureState/可信代码警示条）。
  - **curated 审查模型**：官方源 PR 制；第三方源可自加但 UI 标「未审查」。
- semver 比较迁入 `lc-core/version.rs` 单一来源（市场与更新器共用
  preview 段语义，如 `preview.2 < preview.10`）。

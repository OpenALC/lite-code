# v0.6.1-preview.27

> 编辑器快捷键对齐 VS Code：Ctrl+W 关闭、Ctrl+Tab 切换，设置页可随时查阅全部快捷键。

## 新增

- **Ctrl+W**：关闭当前编辑器。走标签栏同一套关闭逻辑，dirty 标签仍先进入二次确认态；
  自定义「文件 → 关闭标签」菜单同步修复为同一路径（此前对 dirty 标签无反馈）。
- **Ctrl+Tab / Ctrl+Shift+Tab**：在已打开编辑器之间正向/反向循环，少于两个标签时无操作。
- **设置页「快捷键」卡片**：集中展示快速打开、重新打开、关闭/切换标签、侧栏、底部面板、
  设置、主题与缩放快捷键，键位使用 `kbd` 样式，随语言包切换。
- 循环切换只改变激活标签，不打乱标签顺序；关闭后仍可用 Ctrl+Shift+T 原位恢复。

## 验证

- Web：lint / typecheck / `pnpm test`（390 项 / 26 文件）/ build 全绿；
  tabs 新增正向/反向循环与边界回退 2 项。
- Rust 无变更，沿用 607 项基线。
- 真机（Windows Tauri dev）：
  - Ctrl+Tab 从 `index.html` 切到 `abap-*.js`，Ctrl+Shift+Tab 切回；
  - Ctrl+W 关闭当前标签后标签数 7 → 6，Ctrl+Shift+T 恢复为 7；
  - 设置页「快捷键」卡片渲染 10 个 `kbd` 键位，文案与当前中文语言包一致。

## 已知限制

- Ctrl+Tab 循环按标签栏顺序，不维护最近使用（MRU）历史。
- 快捷键固定，暂不支持在设置页自定义键位。

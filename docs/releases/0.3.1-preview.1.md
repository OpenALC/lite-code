> P3（Agent 模式可用）里程碑包。Agent 会话、工具执行、审批、上下文压缩与 MCP
> 已接入桌面端与 headless CLI；编辑器 ↔ Agent 切换保留会话状态。
>
> **发布状态**：P3 预览包。真实 OpenAI / Anthropic 端点的兼容性尚未覆盖，
> 见「已知问题」；本地以 Responses mock 完成工具闭环验证。

## 新增

- **Agent 会话**：Rust 侧 `AgentLoop` 串联 LLM 流、工具授权、执行与结果回填；支持多轮、审批 resume、取消与 25 轮上限。
- **工具与权限**：`read_file` / `write_file` / `edit_file` / `glob` / `grep` / `shell`；`plan` / `chat` / `auto` / `yolo` 四模式，静态+用户黑名单，工作区边界校验。
- **审批卡**：仅本次 / 本会话同类 / 拒绝；`yolo` 每次应用启动需二次确认。
- **LLM 网关**：OpenAI Responses 流式（SSE）；Anthropic Messages 事件解码；`providers.json` + 环境变量密钥。
- **上下文压缩**：工具输出瘦身 → 早期摘要 → 激进压缩；保留工具 call/output 配对；UI 阈值刻度、超阈值变黄、压缩后闪烁与可展开记录。
- **MCP（stdio）**：读取项目 `.mcp.json` 与用户 `~/.lite-code/mcp.json`，握手/工具列表/调用，动态注册 `mcp_<server>_<tool>`，Network 风险审批。
- **环境契约与记忆**：system prompt 注入平台、shell 方言、路径分隔符、工作区；读取全局/项目 `memory.md` 与 `AGENTS.md` / `CLAUDE.md`。
- **Agent UI**：会话流、思考折叠、工具卡、内联审批、composer、停止按钮、上下文刻度条、压缩记录。
- **`lc-cli agent run`**：headless 多轮任务、NDJSON 事件流、`--yes`、退出码 0/1/2。

## 已知问题

1. Anthropic Messages 目前只有事件解码，网络传输未接；请使用 `openai-responses` 端点。
2. MCP 仅支持 stdio `command` 型 server；HTTP/SSE 配置会被忽略并告警；`with_builtins()` 下动态 MCP 工具仅 1 个槽位（保留 `task` / `db_query` 占位）。
3. 取消不会强制中断已发出的 HTTP 流；审批挂起期间取消会留下待审批项（UI 正常路径不会触发）。
4. Windows 下 `.mcp.json` 的 `command: "npx"` 可能因 `.cmd` 解析失败；请使用 `python` / `node` 等可执行文件路径。
5. 安装包未签名；首次运行 SmartScreen 可能提示"未知发布者"。
6. 编辑器 ↔ Agent 的窗口销毁/重建会保留标签与布局；Agent 会话仍绑定进程生命周期，应用退出后不恢复。

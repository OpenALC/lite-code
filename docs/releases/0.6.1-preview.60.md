# v0.6.1-preview.60

**日期**：2026-11-10
**类型**：pre-release
**对应里程碑**：P6 稳定化（鸿蒙历史原生持久化）

### 亮点

- 鸿蒙会话历史从 localStorage 迁移到原生落盘：force-stop 重启后历史不丢，
  配额与 WebView 数据清除不再影响会话留存。

### 新增

- `crates/lc-ohos/src/history.rs`：`history_list/save/load/delete`；
  `<files_dir>/history/<id>.json`，0600 + tmp/rename，4 MiB payload 上限；
  id 路径逃逸校验；超 50 条按 `savedAt` 驱逐最老；`max_session_ordinal`
  支撑重启后会话序号续接（修复重启覆盖旧历史）。
- `Host` 增加 `history_dir`；dispatch 接入 4 命令（裸 JSON 与 providers_*
  一致，shim 解析后对外形状不变）。
- `tauriShim.ts`：history_* 优先 `__lcNative.invoke`，桥缺失或旧宿主
  `not_implemented` 时回退 localStorage；白名单加 4 命令。
  rename/archive/migrate_workspace 仍走 localStorage（已知限制）。

- Web：lint / typecheck / test（413 项 / 28 文件）/ build / build:ohos（无

### 已知问题

| 问题 | 影响 | 规避方式 |
|---|---|---|
| rename/archive/migrate_workspace 仍 localStorage | 重命名/归档不持久 | Ohos 历史面板仅暴露删除；后续补原生命令 |
| 旧 localStorage 历史未迁移 | 升级后旧记录不可见 | 如需平滑升级加一次性迁移 |
| 损坏 JSON 被列表跳过但不驱逐 | 垃圾文件可能积累 | 后续清理任务 |
| history 目录默认 0777（sandbox 内） | 目录权限宽松 | 文件已 0600；可收紧 0700 |

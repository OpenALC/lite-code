# v0.6.1-preview.10

> 预览版：preview.9 供应商管理的安全加固与交互收尾。功能面不变，重点修复
> API Key 的临时文件/备份权限、清除语义与保存竞态。

## 安全加固

- **临时文件 0600**：供应商配置不再使用通用 `write_atomic`；`.tmp` 创建即 0600，
  rename 后才暴露，避免保存窗口内被其它用户读取。
- **加载时收紧权限**：`providers_load` 与 Agent 运行时都走 `ProvidersFile::load_path`，
  发现旧配置权限过宽会 chmod 0600；失败则报错而不是静默继续。
- **备份脱敏**：`.bak` 只保留 baseUrl/模型等非密钥字段，清除/轮换 Key 后旧密钥不会
  残留；主文件与备份在 Unix 下均为 0600。
- **清除语义**：`clearApiKey` 同时清掉 `apiKeyRef`，避免清除本地 Key 后运行时继续
  回退到环境变量旧密钥。
- **Debug 脱敏**：`ProviderConfig` 手写 `Debug`，`apiKey` 永远显示 `<redacted>`，
  防止 panic/日志意外泄露。
- **短 Key 掩码**：长度 < 8 的 Key 整体显示 `••••`，不再回显末四位。

## 交互修复

- 保存期间整个表单 `fieldset disabled`，避免等待响应时继续编辑导致草稿被覆盖；
  保存入口加并发保护。
- 供应商页改为常驻挂载（`v-show`）：切换页签/关闭再打开不丢未保存草稿。
- 模型行使用稳定 key，编辑模型名称时输入框不再丢失焦点；删除按行索引，不受重复 id 影响。
- 保存后保留当前选中的供应商；Anthropic “即将支持”后缀走 i18n；Subagent 文案明确
  “当前仅持久化，尚未接入执行”。

# v0.6.1-preview.12

> 修复：供应商已配置但 Agent 仍显示“请先配置供应商”，以及 401 错误缺少可操作提示。

## 修复

- Agent 空态现在读取 `providers_load`：存在启用供应商、模型与密钥（`apiKey` 或 `env:` 引用）时显示
  “供应商已就绪”，并展示供应商 · 默认模型；否则仍显示配置引导。
- 供应商保存成功会广播 `providers:changed`，Agent 面板立即刷新，无需重开窗口。
- HTTP 401/403 错误追加提示：“Base URL 与 API Key 不匹配，请到供应商页面检查”。
- 说明：401 是供应商配置/凭据问题，不是 Agent 会话创建失败；`session_create` 在配置有效时可正常返回。

## 验证

- Web：lint / typecheck / `pnpm test`（338 项 / 19 文件）/ build 全绿。
- 真机：现有供应商配置下 Agent 空态显示“供应商已就绪”；发送请求返回 401 时显示认证提示。
- Rust 无逻辑变更；沿用 preview.11 的 597 项测试基线。

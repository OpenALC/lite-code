# v0.6.1-preview.67

**日期**：2026-11-11
**类型**：pre-release
**对应里程碑**：P6 稳定化（插件系统六块收官 + db M3 回填）

### 亮点

- **插件系统 v0 收官**：`docs/EXTENSIONS.md` §8 未实现清单从 8 项收敛到 4 项
  明确 v1+ 边界（市场/Webview/签名/API 兼容）。本版落地六块：
  - **插件级 Agent 工具**（`contributes.tools`，Risk::Mutating 走既有审批）；
  - **延迟激活**（`activationEvents` 生效：onCommand/onView 懒激活，`*` 向后兼容）；
  - **声明式主题**（`contributes.themes`，设置页 select 含插件 optgroup，失效回落 dark）；
  - **声明式语言**（`contributes.languages`，Monarch grammar 白名单，内置语言优先）；
  - **插件依赖**（`extensionDependencies`，缺失/Tarjan 环标记 error，稳定拓扑加载序）；
  - **树视图 v1**（`contributes.views`，侧栏可折叠分区，展开懒拉取，节点命令路由）。
- **db M3（契约 v0.9）**：远程连接编辑回填全等往返（port/user/secretRef）；
  connect 错误分类引导（Node 缺失/连接类分流提示）。
- 全部插件贡献面共用同一套安全骨架：清单校验（push_error 只标记插件）、
  路径 canonicalize 防穿越、64KiB 读取帽、web 白名单归一防注入。

### 变更

- `crates/lc-core` ext lane：tools.rs / 延迟激活 / 主题 / 语言 / 依赖 / 树视图
  六块（lc-core 485→504 项）；manifest.rs 共用校验模式；host.rs 拓扑排序 +
  懒激活分发；`read_declared_plugin_file` 公共读取骨架。
- `sidecars/ext-host`：tool/execute + view/children 协议 + ctx.tools/views.register
  + pendingPlugins/pendingViews 懒激活映射（测试 14/14）。
- `apps/web`：pluginThemes/pluginLanguages/pluginViews 三同步 store + 设置页
  主题 select + 资源管理器底部插件视图分区 + 语言/主题/视图注册表
  （web 477→532 项）；`dbConnectionForm` 回填升级 + `dbErrorHint` 错误引导。
- `crates/lc-proto`：契约 **v0.9.0**（DbConnectionInfo 增 port/user/secretRef，
  可选字段向后兼容；golden/TS 绑定同步）。
- `docs/EXTENSIONS.md`：§1 六块声明示例与校验条款、§3 命令面补
  ext_read_theme/ext_read_grammar/ext_view_children、§4 协议补全、
  §8 未实现清单收敛。

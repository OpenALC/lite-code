# v0.6.1-preview.33

> 底部面板接入 LSP 诊断：问题页签、计数、严重级列表与点击跳转。

## 新增

- **问题页签**：底部面板「终端 / 输出 / 问题」可切换，问题页签显示诊断总数徽标。
- **诊断列表**：按路径、行、列排序，展示严重级色点、消息与 `相对路径:行:列`；
  支持错误/警告/信息/提示四级颜色。
- **点击跳转**：优先激活已打开标签，否则读取文件后打开，并通过 `requestReveal` 定位到行；
  复用搜索面板的打开/定位链路。
- **状态栏告警**：有诊断时显示 `⚠ N`，点击打开问题页签。
- 新增 `flattenDiagnostics` 纯函数，按文件/服务器聚合结构摊平并稳定排序。

## 验证

- Web：lint / typecheck / `pnpm test`（401 项 / 28 文件）/ build 全绿；
  lspDiagnostics 新增摊平与空状态 2 项测试。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）：
  - 注入 2 条诊断（1 error / 1 warning）后，问题页签显示 `2`，列表展示两条消息与
    `D:/code/lite-code/apps/web/dist/index.html:3:2` 等位置；
  - 状态栏显示 `⚠ 2`；
  - 先切到其他标签，再点击问题行，编辑器切回 `index.html`（reveal 请求已发出）；
  - 清空诊断后列表回到「没有发现问题」，面板恢复终端页签。

## 已知限制

- 只展示 LSP 诊断，不包含构建/任务输出问题。
- 列表按路径/行摊平，暂不支持按严重级过滤、分组折叠或一键清除。
- 跳到行依赖已打开的 Monaco 编辑器；文件读取失败时静默不跳转。

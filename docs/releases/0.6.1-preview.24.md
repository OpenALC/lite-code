# v0.6.1-preview.24

> Agent 偏好设置：发送键、消息密度与字号，实时应用并持久化。

## 新增

- 设置页 Agent 卡片新增：
  - **发送键**：`Enter 发送 / Shift+Enter 换行`（默认）或 `Ctrl+Enter 发送`；
    无论选择哪种，`Ctrl+Enter` 始终可发送。
  - **消息密度**：舒适（默认）/ 紧凑；紧凑会缩小消息间距、工具卡高度、composer 内边距与顶栏。
  - **Agent 字号**：12–18px，默认 14px；点数值恢复默认。
- 设置写入 `lc.ui.prefs`，Agent 面板通过 `subscribePrefs` 实时接收，无需重开对话。
- 字号通过 `--agent-font` CSS 变量作用于用户/助手消息与 composer；消息流与工具文本同步缩放。
- 发送按钮 tooltip 会显示当前发送键提示。

## 参考

- Kimi Code Desktop 的发送键、密度与排版设置；默认 Enter 发送、Shift+Enter 换行。

## 验证

- Web：lint / typecheck / `pnpm test`（377 项 / 25 文件）/ build 全绿；
  新增 Agent 偏好归一化/持久化测试（非法发送键、密度回落，字号 clamp 12–18）。

    `--agent-font: 16px`，localStorage 同步；
  - 恢复「舒适 / 14px / Enter」后 tooltip 显示「Enter 发送，Shift+Enter 换行」。

## 已知限制

- 密度/字号作用于 Agent 面板（docked 与全宽模式共用），不影响 Monaco 编辑器字号。
- 快捷键设置只覆盖 composer；全局快捷键仍固定。
- 默认改为 Enter 发送，习惯 Ctrl+Enter 的用户可在设置中切回。

# v0.6.1-preview.37

> 文件树补齐 VS Code 键盘导航：方向键移动、展开/折叠、Home/End 跳首尾。

## 新增

- **Roving tabindex**：文件树只保留一个 Tab 焦点；聚焦行使用蓝色描边与浅蓝底。
- **方向键**：
  - ↑/↓ 在可见文件/目录间移动；
  - → 展开折叠的目录；
  - ← 折叠已展开目录，否则跳到父目录；
  - Home/End 跳到第一个/最后一个可见项。
- **Enter/Space** 沿用按钮原生行为：打开文件或展开/折叠目录。
- 切换工作区或刷新文件树时重置焦点，避免指向已不存在的路径。

## 验证

- Web：lint / typecheck / `pnpm test`（404 项 / 28 文件）/ build 全绿。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev，tangshan 工作区 22 个可见行）：
  - 聚焦 `.claude` 后按 ↓，焦点移动到 `.playwright-mcp`，`tabIndex` 保持 0；
  - 对折叠目录按 →，`aria-expanded` 变为 `true`；
  - 再按 ←，`aria-expanded` 回到 `false`，焦点仍在原目录。

## 已知限制

- → 展开后不自动进入第一个子项；← 在文件上跳到父目录。
- 暂不支持键入首字母快速定位、F2 重命名等 VSC 树快捷键。
- 键盘导航只作用于文件树；打开编辑器列表仍用 Tab/点击。

# v0.6.1-preview.65

**日期**：2026-11-10
**类型**：pre-release
**对应里程碑**：P6 稳定化（lc-host M2 会话编排骨架 + M3a 事件出口统一 + M3b 完成事件组合）

### 亮点

- **lc-host M2（鸿蒙会话表迁移）**：鸿蒙会话编排（句柄状态原语/会话表/回收/
  序号）整体下沉到共享 crate `lc-host`——会话生命周期语义（running 保护、
  alive 迟到抑制、按创建序回收、同锁 begin_turn）由同一份代码与同一组单测
  承载（当前承载鸿蒙侧；桌面侧保留其命令通道式注册表，见 M3c 决定）。
- **lc-host M3a（两端事件信封复用）**：`CoreEventSink` trait 与 `envelope()`
  构造下沉，桌面/鸿蒙信封形状与 seq 语义（1 起单调）完全一致；桌面首信封
  seq 0→1（web 不消费 envelope seq，无影响）。

### 变更

- `crates/lc-host` 新增 `sessions` 模块：`SessionHandle`（info/cancel/running/
  alive 原语 + model/thinking 元数据）、`SessionEntry<P>`（泛型宿主负载，
  lc-ohos = `AgentLoop` 槽位）、`Sessions`（map + limit + ordinal，插入即回收，
  `begin_turn` 同锁查表 + CAS running）；9 项新单测（回收序/running 保留/
  alive 抑制/并发轮次拒绝/unknown not_found/种子续接）。
- `crates/lc-ohos`：删除本地 `SessionHandle`/`reclaim_terminated_sessions`/
  `begin_turn`/`MAX_SESSIONS`/`next_session`（净 -194 行），改接 lc-host
  `Sessions`；错误文案与锁序 1:1 保留，36 项测试不改语义全过。
- `crates/lc-host` envelope 模块（M3a）：新增 `CoreEventSink` trait、
  `envelope()` 构造、`Seq::from_u64` 种子；`emit_envelope` 基于 `envelope()`。
- `apps/desktop`（M3a）：`EventSink` 改重导出 lc-host `CoreEventSink`，
  `next_envelope`/`AtomicU64` seq 删除；`db.rs` 的 `DbEvents` 同样切换到
  `Seq`；lc-desktop 增加 lc-host workspace 依赖。
- 文档：`docs/plans/lc-host-extraction.md` M2 完成记录 + M3 实施要点（研读
  desktop 后修订切片：3a 事件出口 / 3b 完成事件组合下沉 lc-core / 3c 桌面
  表切换**决定不做**（语义本质不同）/ 3d ApprovalHook 不做）。
- `crates/lc-core`（M3b，合并自 `host/m3b-completion-events`）：
  `agent::events::completion_events` 完成事件排序契约下沉（session_state
  在前 + 三终态区分：end_turn/approval_required/permission_denied），桌面
  `agent.rs` 删私有同名 fn 改调共享实现；lc-core +1 项排序契约单测。

# v0.6.1-preview.30

> 编辑器标签补齐 VS Code 右键菜单；标题栏品牌标记切换为新 Logo。

## 新增

- **标签右键菜单**（6 项）：
  - 关闭
  - 关闭其他
  - 关闭右侧（右侧无标签时禁用）
  - 关闭已保存
  - 复制路径
  - 在资源管理器中显示（浏览器演示模式禁用）
- 批量关闭只关闭干净标签；dirty 标签保持打开，避免绕过二次确认造成数据丢失。
- 「关闭其他」后始终激活保留的标签，即使其他标签全部是 dirty、没有实际关闭。
- 菜单为 fixed 定位，自动夹在窗口内；点击外部或 Escape 关闭。
- 复制路径复用统一 `execCommand` 剪贴板工具，不触发 WebView2 权限条。
- **标题栏品牌标记**：`.brand-mark` 改用 `favicon.png`（新蓝色 Logo），移除 Agent 模式/亮色主题下的
  灰色渐变覆盖，两种模式视觉一致。

## 验证

- Web：lint / typecheck / `pnpm test`（393 项 / 26 文件）/ build 全绿；
  tabs 新增「关闭其他 / 关闭右侧 / 关闭已保存」3 项，覆盖 dirty 保留与激活顺延。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）：
  - 右键 `index.html` 弹出 6 项菜单，全部可用（右侧有标签、路径存在、Tauri 环境）；
  - 点击「复制路径」捕获到 `D:\code\lite-code\apps\web\dist\index.html`，菜单随即关闭；
  - `.brand-mark` 计算样式为 `url("http://localhost:5173/favicon.png")`，标题栏截图确认显示新 Logo。

## 已知限制

- 批量关闭遇到 dirty 标签时直接保留，不逐项弹确认；需要时可再单独关闭或保存。
- 菜单键位不随设置页快捷键卡片变化；「在资源管理器中显示」依赖 Tauri `fs_reveal`。
- 文案随语言包切换，但键位标签保持 VS Code 习惯。

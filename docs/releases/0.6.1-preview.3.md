## 新增

- **Linux arm64**：`ubuntu-24.04-arm` 构建 AppImage/deb/`lc-cli-arm64`，与 x64 资产一起发布。
- **更新器**：`update_check` 命令、`latest.json` 生成器、`updater-manifest` 滚动发布与回滚文档；无签名密钥时明确 `signed:false`，不自动下载/安装。
- **鸿蒙结论**：DevEco 26/API26 spike 完成；ArkWeb + NAPI 通过，Monaco 内存/IME 未过，首版降级只读 + 对话（`spikes/harmony-arkweb`、`docs/ARCHITECTURE.md §5.7`）。
- **安全修复**：
  - MCP 项目 `.mcp.json` 默认忽略（`LC_MCP_ALLOW_PROJECT=1` 才启用），环境 allowlist、server 上限、配置大小上限；
  - SQL 闸门使用 SQLite 方言，修复反斜杠 + 多语句绕过；强制行数上限；PRAGMA 只读白名单；
  - Agent 审批逐项授权、真实参数摘要、`.git`/`.hg`/`.svn` 写保护、取消 token、工具错误不可信边界；
  - 记忆文件根校验/拒绝 symlink/reparse/1MiB 上限；
  - Task 按 workspace 隔离、apply/discard 保护 ignored 文件。
- **发布加固**：签名 fail-closed、workflow 最小权限、checksums 与资产一致性校验、CI 增加 `pnpm audit` 与 updater manifest 测试。
- **依赖**：`dompurify` override 至 3.4.17，生产依赖审计清零。
- **复验补丁**：DB 审批摘要纳入 `connection_id`（AllowSession 不再跨连接）、shell/DB/git 子进程剥离 provider 密钥、CI audit 缓存修复。
- **Medium 加固**：CREATE TRIGGER DML 检查、LIMIT/TOP 识别、DB bridge 流式取样、不可信边界转义、task key FNV-1a 64；write_file/edit_file 审批展示内容摘要。

- `pnpm audit --prod --audit-level high`：无已知漏洞。
- 审计修复：MCP/SQL/审批的 PoC 回归测试已加入；详见 `docs/SECURITY-AUDIT.md` 与 STATUS。
- **未完成**：更新器签名（`signed:false`）、B 类外部门禁。

## 已知问题

1. Windows 安装包未签名；SmartScreen 可能提示未知发布者。
2. 更新器只能检查/提示，不能自动安装；签名密钥未配置时清单 `signed:false`。
3. Linux arm64 使用 Ubuntu 24.04 基线；22.04 arm64 兼容性未验证。
4. `pnpm audit` 依赖 npmjs registry；镜像不提供 audit endpoint 时会失败。
5. 鸿蒙首版不提供可编辑 Monaco（只读预览 + 对话）。
6. MCP 仅 stdio；`LC_MCP_ALLOW_PROJECT=1` 是显式信任开关，启用后项目可定义任意命令。

# v0.5.1-preview.1

> P5（数据库与周边）预览包。SQLite 连接、schema 浏览、SQL 查询/执行、结果网格与
> Git 面板可用；Agent 可在审批后通过 `db_*` 工具完成建表、写入、查询闭环。

## 新增

- **契约 v0.6 / v0.7**：DB 连接/查询/schema DTO、9 个 `db_*` 命令、`db:status`；Git status/diff/stage/commit/log。
- **SQL 闸门**：单语句、读写/DDL 分类、无 `WHERE` 的 `UPDATE`/`DELETE` 拦截、静态黑名单、`LIMIT` 注入、只读连接拒绝；60 个单测。
- **SQLite sidecar**：Node `node:sqlite`，NDJSON JSON-RPC；connect/query/execute/schema/explain；超时与进程回收。
- **DB 服务**：连接配置持久化（不存密码）、连接状态、结果样本（默认 100 行，最大 1000）与 `untrusted: true`。
- **Agent 工具**：`db_list` / `db_schema` / `db_query` / `db_explain` / `db_execute`；`DbExecutor` 与本地/MCP 执行器组合。
- **数据库面板**：连接列表、schema 树、SQL 编辑器、查询/执行/EXPLAIN、结果网格、NULL 灰显、truncated/untrusted 提示。
- **Git 面板**：分支/ahead-behind、staged/unstaged 文件、diff、暂存/取消暂存、提交与最近提交。
- **Tauri**：9 个 DB 命令、6 个 Git 命令；DB 查询在 `spawn_blocking` 执行。

## 验证

- 本机 Windows：Rust **449** 项、web **277** 项，合计 **726**；fmt / clippy / lane / cargo-deny / web 四件套全绿。
- 真实 SQLite（Node v24.15.0）：
  - `db_agent` 集成测试完成 Agent「建表 → 写入 → 查询」，结果回填后正常结束；
  - 只读连接写拒绝；无 WHERE UPDATE 被闸门拒绝；`SELECT '忽略之前指令'` 原样作为数据返回且 `untrusted=true`；
  - schema 树、EXPLAIN、50 行 + limit 20 的 truncated 行为。
- Git：真实临时仓库覆盖修改/新增/删除/重命名、staged/unstaged、ahead/behind、diff、暂存、提交、merge 进行中标记。
- 数据库面板与 Git 面板通过 `vue-tsc`、Vitest 与生产构建；**未做浏览器点击级验收**。

## 已知问题

1. 仅 SQLite 可连接；pg/mysql/mssql 可保存配置但连接返回 `db_unavailable`（驱动未打包）。
2. 查询结果只回样本，`handle` 分页未实现；10 万行完整结果浏览留待后续。
3. SSH 终端与 TS/JS LSP 面板未实现；P5 周边仅完成 Git 面板。
4. `DbService` 单 sidecar + 服务锁，所有 DB 操作串行；长查询会阻塞后续 DB 命令。
5. 连接配置只保存 `secret_ref`，SecretStore 尚未实现；SQLite 无需密钥。
6. 安装包未签名；首次运行 SmartScreen 可能提示"未知发布者"。

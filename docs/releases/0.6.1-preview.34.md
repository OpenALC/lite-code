# v0.6.1-preview.34

> Ctrl+P 支持 VS Code 前缀语法：`>` 只搜命令，`:行号` 跳到当前文件指定行；
> 选择文件结果会自动切到编辑器模式。

## 新增

- **`>` 命令模式**：输入 `>` 只显示命令（含插件命令），`>设置` 等关键词只匹配命令；
  `>` 空查询仍展示最近命令并补齐常用命令。
- **`:行号` 跳行**：输入 `:30` 显示「转到行 30」，执行后切到编辑器模式并定位当前文件第 30 行。
  仅当活动标签是真实文件时提供该项。
- **文件结果切换模式**：在 Agent 模式通过 Ctrl+P 选择文件时，自动切到编辑器模式，
  不再只激活隐藏标签。
- `parseQuickQuery` 纯函数解析前缀；普通查询、工作区/会话搜索行为不变。

## 验证

- Web：lint / typecheck / `pnpm test`（404 项 / 28 文件）/ build 全绿；
  quickPalette 新增前缀解析 3 项（`>`、`:数字`、普通查询）。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）：
  - `>` 显示 10 条命令、无文件；`>设置` 仅剩「设置 / Ctrl+,」；
  - `:30` 显示「转到行 30 / index.html」，执行后 shell 退出 Agent 模式并激活 `index.html`；
  - `login` 普通查询仍显示「在文件中搜索」。

## 已知限制

- `:行号` 只支持当前活动文件，不支持 `文件:行号` 组合。
- `@` 符号跳转未实现（暂无统一符号索引）。
- `>` 模式不含「在文件中搜索」项，符合命令面板语义。

# v0.6.1-preview.52

**日期**：2026-11-09
**类型**：pre-release
**对应里程碑**：P6 稳定化（鸿蒙供应商配置）

### 亮点

- 鸿蒙宿主实现 `providers_load` / `providers_save`：对话页从「请先配置供应商」空态
  变为「供应商已就绪」，模型 pill / 上下文预算跟随所选模型。

### 新增

- `crates/lc-ohos`：
  - `providers_load`：复用 `lc-core::llm::ProvidersFile::load_path`；文件缺失或
    JSON 损坏返回默认空视图，不报错。
  - `providers_save`：形状对齐桌面 `{ input }`；校验必要字段与 `models` 非空，
    复用 lc-core 校验 provider/model 引用与 budget；空 key 保留旧值、
    `clearApiKey` 清除；写入复用 lc-core 0600 + tmp/rename 并清理备份密钥。
  - camelCase `ProvidersView`（字段与桌面 `providers.rs` 完全对齐，密钥只回
    `hasApiKey` + 末四位 hint）。
  - `session_create` 预算跟随所选模型：`model` 参数命中 `providers.json` 时
    `context_k/compress_at_k` 取该模型配置（`compressAtK` 收敛到 `contextK` 内），
    缺省/未知回退 400/300。
- ArkTS 首启：预置 `local-stub` provider + `stub-chat` 模型（`contextK:100`、
  `compressAtK:80`，密钥仅占位 `apiKeyRef`）；旧空 `models:[]` 文件自动补写模板。
- 单测新增 5 项：load 缺失/损坏、save→load round-trip（含 0600 断言）、非法入参
  拒绝、会话预算跟随模型。

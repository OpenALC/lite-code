# v0.6.1-preview.51

**日期**：2026-11-09
**类型**：pre-release
**对应里程碑**：P6 稳定化（鸿蒙 NAPI 桥与真实 core）

### 亮点

- 鸿蒙外壳接入真实 core：`liblc_ohos.a`（Rust 静态库，x86_64 + aarch64 OHOS 目标）
  经 NAPI 链接进 HAP；模拟器端到端跑通「真实 fs 文件树 + 流式对话 + 取消」。

### 新增

- `crates/lc-ohos/src/ffi.rs`：C ABI（`lc_ohos_init/call/set_event_sink/dispose/free`）、
  `catch_unwind`、`LC_PROVIDERS_FILE`/`TMPDIR` 注入。
- NAPI 胶水重写：`napi_init.cpp`（init / invoke async work / setEventSink
  threadsafe function / dispose + env cleanup hook），事件经 `runJavaScript`
  注入 `window.__lcOhosEmit`；CMake 按 `OHOS_ARCH` 链接静态库与系统库。
- ArkTS `NativeBridge`：`javaScriptProxy` 暴露 `__lcNative.invoke`（Promise 方法
  只放 `methodList`——放 `asyncMethodList` 会 resolve 成 0，实测坑）；首启复制
  `sample-workspace`（三级目录、中文内容）到 filesDir 并初始化 Host/providers。
- `scripts/ohos/build.mjs` 新增 `[2/8] cargo build lc-ohos`：从 `DEVECO_SDK_HOME`
  推导 clang/llvm-ar，构建 x86_64 与 aarch64 两个 OHOS target
  （路径含空格走 `CC_/AR_/LINKER` 环境变量，不走 RUSTFLAGS）。

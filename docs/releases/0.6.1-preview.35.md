# v0.6.1-preview.35

> VSC 模式与 Agent 模式统一为同一套主题令牌：Logo 蓝 `#0A84FF`、相同圆角/间距/卡片，
> 深浅色表现一致。

## 变更

- **统一色板**：删除 Agent 模式单独的 Kimi 中性灰令牌（含亮色覆盖），两种模式共用
  `tokens.css` 的背景、面板、边框与文字层级。
- **Logo 蓝主题色**：
  - 深色/亮色 `--accent` 均改为 `#0A84FF`；
  - hover、soft、line 按深浅色分别调整对比度；
  - 活动栏、标签下划线、聚焦描边、按钮、模式切换、会话选中态统一使用该蓝色。
- **统一卡片**：Agent 模式不再全幅无边框；会话侧栏与主区恢复 6px 间距、`--r` 圆角、
  1px 边框，与编辑器模式一致；活动栏仍只在 Agent 模式隐藏。
- **Agent 细节**：用户消息气泡改为蓝边 + 10% 蓝底；composer 与会话搜索聚焦改为蓝色描边；
  模式切换 active 使用蓝色软底。
- **编辑器**：Monaco 背景与面板令牌对齐，光标/选区/链接改为 Logo 蓝；欢迎页标识改用应用 Logo。

## 验证

- Web：lint / typecheck / `pnpm test`（404 项 / 28 文件）/ build 全绿。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）：
  - 亮色与深色各截取 Agent / VSC 两种模式：卡片间距、圆角、边框一致；
  - Agent 用户气泡为蓝色描边，模式切换 active 为蓝底蓝字，编辑器选区/光标为蓝色；
  - 切换主题后两种模式同步变色，刷新后偏好保留。

## 已知限制

- 强调色固定为 Logo 蓝，暂不提供自定义主题色选择。
- Monaco 主题颜色为硬编码令牌副本，调整 `tokens.css` 时需同步 `CodeEditor.vue`。
- Agent 顶栏仍保留 48px 高度与居中对话列，属于布局差异而非配色差异。

## 参考

- Logo 主色采样 `#0185FE / #0082FC / #0A92FE`，取 `#0A84FF` 作为统一强调色。

# v0.6.1-preview.66

**日期**：2026-11-11
**类型**：pre-release
**对应里程碑**：P6 稳定化（子代理 swarm：插件 Agent 工具 / LSP 三件套 / MySQL·PG / 设置浮层）

### 亮点

- **设置页重做（模式无关模态浮层，Kimi Code/Zcode 行为）**：任何入口打开
  设置不再跳转 VSC 模式——浮层置顶、Esc/遮罩/× 关闭、打开时焦点移入并
  Tab 循环锁定、屏蔽后台编辑快捷键（Ctrl+S/Ctrl+F/Ctrl+W 等，输入框原生
  编辑键不受影响）；「供应商」分区内嵌完整供应商管理（单一编辑实例，杜绝
  双实例互相覆盖）；旧版持久化的设置/供应商页签恢复时自动过滤。
- **插件级 Agent 工具**：第三方插件经 `contributes.tools` 向 AgentLoop
  贡献 LLM 可调用工具——ext-host `tool/execute` 协议（30s 超时、128KiB
  截断、`[UNTRUSTED PLUGIN CONTENT]` 边界），一律 `Risk::Mutating` 走既有
  审批队列（auto 询问/yolo 放行/plan 拒绝），审批语义零改动。
- **LSP 编辑器智能三件套（契约 v0.8）**：completion/hover/definition
  按路径请求（10s 超时、未打开文件结构化错误），Monaco 异步 provider
  仅对已启动 server 的语言注册（保留内置建议），跨文件跳转经官方
  `registerEditorOpener` 落到标签系统。
- **MySQL/PostgreSQL 端到端**：连接管理 UI（host/port/env 密码名不落盘
  明文/只读开关）、结果集字节截断加固（4KiB 单元格 / 128KiB 预算）、
  CI 引入真实 PG/MySQL 服务容器集成测试。

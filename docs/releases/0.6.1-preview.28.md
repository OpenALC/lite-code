# v0.6.1-preview.28

> Ctrl+P 现在能搜到历史会话的消息正文，而不只是标题与元数据。

## 新增

- **历史摘要携带正文**：`history_list` 为每个会话生成最多 4000 字符的消息摘要
  （`excerpt`），按消息顺序拼接用户/助手文本，跳过空白消息。
- **快速打开检索正文**：Ctrl+P 的会话匹配字段在标题、模型、模式、工作区路径之外
  新增 `excerpt`，输入正文中的关键词即可定位会话。
- **会话侧栏搜索对齐**：Agent 侧栏的会话过滤同样匹配 `excerpt` 与工作区路径，
  两处搜索行为一致。
- **浏览器演示模式对齐**：无 Tauri 时由 localStorage 快照计算同样的 `excerpt`，
  演示模式与桌面端行为一致。
- 摘要只用于检索，不进入会话列表的可见文案；列表体积随会话数线性增长但有上限。

## 验证

- Web：lint / typecheck / `pnpm test`（390 项 / 26 文件）/ build 全绿；
  quickPalette 覆盖正文命中，bridge 摘要夹具同步 `excerpt`。
- Rust：`cargo test -p lc-desktop --locked history` 7 项通过；
  新增「摘要按消息顺序拼接并跳过空白」1 项，桌面端基线 98 → 99。
- 真机（Windows Tauri dev）：
  - `history_list` 返回两条 tangshan 会话，`excerpt` 分别以「继续，用一句话总结。」与
    「用一句话说明这个项目是什么。」开头；
  - Ctrl+P 输入 `TSPL2`（只出现在助手回复正文）命中这两条会话，并显示「tangshan · 历史会话」。

## 已知限制

- 每个会话只索引前 4000 字符；超长会话靠后的内容搜不到。
- 只索引 `messages[].text`，不包含思考过程、工具输出与附件正文。
- 子串匹配，不做分词、拼音或模糊纠错；摘要长度上限后续可按需调整。

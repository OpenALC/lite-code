# v0.6.1-preview.6

> 预览版：preview.5 的 UI/搜索整改复验版。修复独立审计发现的搜索参数、设置入口与
> 编辑器生命周期问题；功能面与 `v0.6.1-preview.5` 相同。

## 修复（审计 High）

- **`fs_search` 参数命名**：补 `rename_all = "snake_case"`。此前 Tauri 2 按 camelCase
  取键，前端传入的 `case_sensitive` / `max_results` 被静默丢弃，导致“区分大小写”开关
  与 500 行上限实际无效。
- **搜索阻塞主线程**：命令改为 `async` + `spawn_blocking`，遍历/读文件不再占用 Tauri
  主线程；大工作区搜索时窗口保持响应。

## 修复（审计 Medium）

- Ctrl+, / 帮助 > 关于 / 状态栏“设置” 统一打开编辑器区设置页签；不再出现侧栏空白。
- 搜索侧栏改为常驻挂载（`v-show`），切换资源管理器/任务/搜索时保留查询、结果与
  Aa / `.*` 状态；顶部“在文件中搜索”用 `{query, seq}` 种子，重复同一关键词也会重跑。
- 搜索侧栏监听工作区切换：清空旧结果并按当前关键词重跑，避免点击旧根下的路径。
- 编辑器定位请求增加消费标记：从设置页签返回文件时不再重放上一次搜索命中。
- CodeEditor 卸载时移除窗口级 click/keydown 监听；Monaco 动态 `import` 返回后检查
  组件是否已卸载，避免在空 host 上创建编辑器。
- 搜索结果 `truncated` 判定：多探一条，恰好 500 条不再误报；单文件 100 行上限会正确
  标记为已截断。
- 非法正则错误按界面语言本地化，英文界面不再显示 Rust 的中文错误。

## 验证

- Rust：fmt / clippy / `cargo test --workspace --locked` 全绿，本机 **543** 项
  （`fs::search` 11 项、`db_agent` 集成 2 项）。
- Web：lint / typecheck / `pnpm test`（**316** 项 / 17 文件）/ build 全绿。
- 真机 Tauri/WebView2 复验：
  - 大小写开关：`FS_SEARCH` 不敏感 11 条 → 敏感 0 条 → 关闭恢复 11 条。
  - Ctrl+, 打开设置页签；搜索查询在资源管理器↔搜索切换后保留。
  - 原生文件夹选择器、命中跳转、文件树/编辑器右键、拖拽移动、主题/缩放/设置页。
- `scripts/check-lanes.sh` 通过。

## 已知问题

1. PostgreSQL / MySQL / SQL Server 驱动已打包，但本机无真实服务器；仅验证驱动加载、
   参数映射与失败路径，未做端到端查询。
2. 搜索每行只返回首个匹配，单次最多 500 行；不支持替换与搜索历史。
3. Windows 安装包未签名；更新器清单 `signed:false`。
4. Linux arm64 使用 Ubuntu 24.04 基线，22.04 arm64 兼容性未验证。
5. 鸿蒙首版仍不提供可编辑 Monaco（只读预览 + 对话）。
6. MCP 仅 stdio；项目 `.mcp.json` 需 `LC_MCP_ALLOW_PROJECT=1` 显式开启。

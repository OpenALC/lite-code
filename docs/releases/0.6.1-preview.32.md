# v0.6.1-preview.32

> Ctrl+P 空查询时显示最近打开的文件与最近命令，并让输入后的结果也按最近使用排序。

## 新增

- **空查询最近列表**：Ctrl+P 不再是一片空白，最多显示 6 个最近文件 + 4 个最近命令。
- **最近文件**：激活真实文件标签时记录（设置/供应商/样例缓冲区不计入），记录按标签 id
  去重、新记录置顶，最多保留 10 条；持久化到 `lc.quick.recent`。
- **最近命令**：执行命令面板中的内置命令或插件命令时记录，规则同上。
- **回填**：最近项不足时用其他打开文件与常用命令补齐，保持列表可用。
- **输入后排序**：匹配的文件/命令把最近使用过的排在前面，其余保持原相对顺序。
- 纯函数 `normalizeQuickRecent` / `rememberRecent` / `sortByRecent` 独立可测。

## 验证

- Web：lint / typecheck / `pnpm test`（399 项 / 28 文件）/ build 全绿；
  新增 quickRecent 3 项（去重截断、稳定排序、非法存储归一化）。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）：
  - 清空记录后 Ctrl+P 显示 5 个文件 + 4 个命令；
  - 选择 `index.html` 后重新打开，`index.html` 排在文件首位，其余文件自动回填；
  - 执行「设置」命令后重新打开，「设置」排在命令首位，其余命令回填。

## 已知限制

- 只记录当前打开的标签；已关闭文件不会出现在最近列表，除非重新打开。
- 命令记录只覆盖命令面板执行路径；从菜单/快捷键执行的命令不计入。
- 最近记录按 WebView 本地存储保存，不跨设备同步。

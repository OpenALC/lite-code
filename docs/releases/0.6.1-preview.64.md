### 亮点

- 新 crate `lc-host`（共享宿主编排）落地 M1：事件信封/seq 出口原语，
  鸿蒙宿主切换为共享实现——桌面/鸿蒙统一信封形状与 seq 语义的第一步

- `crates/lc-host`（workspace 新成员）：`envelope` 模块——`EventSink`、
  `Seq`（内部 Arc，可 clone 跨 worker 共享、1 起单调）、`emit_envelope`；
  3 项单测（单调性、信封 seq+事件、无 sink 不消耗 seq）。
- `crates/lc-ohos`：删除本地 `EventSink`/`emit`，改 `lc_host::envelope`
  （`EventSink` 以 `pub use` 保持兼容）；无行为变化。

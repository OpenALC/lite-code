# v0.6.1-preview.36

> Agent 消息流不再强制跟随输出：用户上翻后保持当前位置，并显示「回到底部」按钮。

## 新增

- **跟随输出开关**：距底部 48px 内视为跟随，新消息/流式增量自动滚到底；
  用户上翻超过阈值后停止强制滚动，便于阅读历史。
- **回到底部按钮**：不在底部且有消息时，在 composer 上方显示圆形下箭头；
  点击回到底部并恢复跟随输出；悬停使用主题蓝描边。
- 发送消息、新建会话、切换会话时自动恢复跟随并滚到底。

## 验证

- Web：lint / typecheck / `pnpm test`（404 项 / 28 文件）/ build 全绿。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）：
  - 注入 48 条消息撑高滚动区（`scrollHeight 4239 / clientHeight 557`）；
  - 滚到顶部后按钮出现；点击后 `scrollTop 3682`（= 4239 - 557），按钮随即隐藏；
  - 刷新后注入会话清除，应用回到空会话。

## 已知限制

- 阈值固定 48px，不提供设置项。
- 按钮不显示未读消息数量；仅有消息时出现。
- 紧凑密度下按钮位置随 composer 高度自适应，仍保持 24px 右边距。

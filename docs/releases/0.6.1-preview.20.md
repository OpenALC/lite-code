# v0.6.1-preview.20

> Agent 模式加入 Git 变更侧栏；排队消息可点击载回 composer 编辑。

## 新增

- **Agent Git 侧栏**：Agent 头部新增 Git 按钮，打开右侧 420px（响应式 clamp）变更栏。
  - 复用现有 `GitPanel`：分支/上游/ahead-behind、staged/unstaged、逐文件暂存/取消暂存、
    提交、最近提交与 Diff。
  - 切换工作区时随 `refreshGit` 刷新；关闭按钮返回全宽对话。
  - 编辑模式仍使用原右侧「源代码管理」标签，功能不变。
- **排队消息编辑**：点击队列中的消息，把它载回 composer（含附件），并从队列移除；
  可直接修改后再次发送。队列仍支持单条移除与清空。

## 参考

- Kimi Code Desktop 的右侧 rail（Git/terminal/preview）与 queue 项交互；
  本版只移植 Git rail，terminal/preview 仍待后续。

## 验证

- Web：lint / typecheck / `pnpm test`（364 项 / 22 文件）/ build 全绿。
- Rust 无变更，沿用 607 项基线。
- 真机（Windows Tauri dev）：
  - 在 `D:\code\lite-code` 工作区打开 Git rail，显示 `main`、上游 `origin/main`、
    5 个未暂存文件、提交表单与最近提交；Diff 列可见。
  - 在审批挂起时排队一条消息，点击队列项后队列清空、composer 恢复原文与附件。
  - 非 Git 工作区（`tangshan`）显示可读的 “not a git repository” 错误，不影响对话。

## 已知限制

- Agent rail 目前只有 Git，没有 Kimi 的 terminal、preview、turn diff/checkpoint。
- 排队仍是前端顺序队列，不支持 steer、编辑重发或按轮回滚。
- Git rail 复用现有 GitPanel，窄屏下 Diff 列会压缩。

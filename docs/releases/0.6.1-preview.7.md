# v0.6.1-preview.7

> 预览版：在 preview.6 审计修复基础上补齐快速打开面板的关闭行为。
> 功能面与 preview.5/6 相同，本版仅含交互修复，作为 preview.6 的重建。

## 修复

- **快速打开（Ctrl+P / 顶部搜索）点击外部不关闭**：面板打开后点击编辑器/文件树/侧栏，
  下拉层仍然浮在标签栏上方并保留旧查询。现在点击 `.quick-wrap` 以外区域会立即收起并
  清空查询；点击面板内条目不受影响（`pointerdown` 捕获阶段判断，先于条目 click）。
- 其余修复与 `v0.6.1-preview.6` 相同：`fs_search` 参数命名（大小写/上限生效）与
  `spawn_blocking` 异步执行、设置入口统一、搜索侧栏状态保留、定位请求消费、CodeEditor
  监听清理、结果截断判定、非法正则文案本地化。

## 验证

- Rust：`cargo fmt --check` / `cargo clippy -D warnings` / `cargo test --workspace --locked`
  全绿；本机 543 项（`fs::search` 11 项、`db_agent` 集成 2 项）。
- Web：lint / typecheck / `pnpm test`（316 项 / 17 文件）/ build 全绿。
- 真机 Tauri/WebView2：点击外部关闭快速打开并清空查询；大小写开关 11→0→11；
  Ctrl+, 打开设置；搜索查询跨视图保留；原生文件夹选择器、右键、拖拽、主题/缩放正常。
- `scripts/check-lanes.sh` 通过。

## 已知问题

1. PostgreSQL / MySQL / SQL Server 驱动已打包，但本机无真实服务器；仅验证驱动加载、
   参数映射与失败路径，未做端到端查询。
2. 搜索每行只返回首个匹配，单次最多 500 行；不支持替换与搜索历史。
3. Windows 安装包未签名；更新器清单 `signed:false`。
4. Linux arm64 使用 Ubuntu 24.04 基线，22.04 arm64 兼容性未验证。
5. 鸿蒙首版仍不提供可编辑 Monaco（只读预览 + 对话）。
6. MCP 仅 stdio；项目 `.mcp.json` 需 `LC_MCP_ALLOW_PROJECT=1` 显式开启。

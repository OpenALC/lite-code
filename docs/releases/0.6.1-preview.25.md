# v0.6.1-preview.25

> Ctrl+P 快速打开接入工作区与历史会话：一次搜索直达任意项目与存档对话。

## 新增

- **Ctrl+P 搜索工作区**：输入项目名或路径即可切换工作区；选中后自动加载并切到 Agent 模式。
- **Ctrl+P 搜索历史会话**：匹配会话标题、模型、模式与工作区路径；结果附带工作区名与
  「历史会话 / 已归档」标识。
- **选择会话即恢复现场**：若会话属于其他工作区，先切换工作区，再读取 app-local 存档并
  还原消息流，直接进入 Agent 模式继续对话。
- 结果排序固定为「工作区 → 历史会话 → 已打开标签 → 命令 → 在文件中搜索」，总计最多 10 条，
  与 VS Code 快速打开的长度上限一致。

## 说明

- 会话搜索只覆盖标题/模型/模式/工作区路径，**不检索消息正文**；正文检索需要额外索引，
  留待后续版本。
- 工作区匹配取前 4 条，会话匹配取前 4 条，为标签与命令保留位置。

## 验证

- Web：lint / typecheck / `pnpm test`（380 项 / 26 文件）/ build 全绿；
  新增 `quickPalette` 3 项纯函数测试（标题/模型/工作区命中、空查询、条数上限）。
- Rust 无变更，沿用 607 项基线。
- 真机（Windows Tauri dev）：
  - Ctrl+P 输入「继续」出现「继续，用一句话总结。 tangshan · 历史会话」，
    点击后切到 `D:\code\tangshan` 并加载 2 条历史消息；
  - 输入「lite-code」出现工作区与文件结果，点击切到 `D:\code\lite-code`。

## 已知限制

- 归档会话可在快速打开中直接恢复；恢复后仍保持归档状态，不会自动取消归档。
- 搜索不做拼音/模糊纠错，按子串匹配。

# v0.6.1-preview.55

**日期**：2026-11-09
**类型**：pre-release
**对应里程碑**：P6 稳定化（鸿蒙离线回退提速）

### 亮点

- 鸿蒙宿主 provider 预探：不可达时 stub 回退从 ~5.5s 降到 ~1.3s
  （800ms TCP 预探预算 + 500ms stub）。

### 变更

- `crates/lc-ohos`：
  - `probe_target`：从 http(s) baseUrl 解析 host:port（默认端口 80/443、显式端口、
    userinfo、IPv6）；非 http(s) 或无法解析返回 None（按可达处理，交原 HTTP 报错路径）。
  - `unreachable_target`：`TcpStream::connect_timeout` 在 800ms 总预算内探测；
    DNS 失败按可达；仅 TCP 连不上视为不可达；https 只探 TCP 不验 TLS。
  - `RealAgentFactory::create` 构造 ureq 传输前先预探；不通直接走既有工厂失败
    分支 → 20 个 `[stub]` delta + `done("stub")`，不再进入 5s 连接超时。
  - 原有语义不变：预探通过但 HTTP/SSE 失败仍按 `LoopError::Llm` + 可见输出判断；
    有可见输出后的错误不伪装成 stub。
- 单测 15 → 19 项：不可达 1s 内回退（耗时断言）、URL 解析规则、TCP 探测
  可达/拒绝、401 仍回退 stub、可见输出后错误不伪装。

### 已知问题

| 问题 | 影响 | 规避方式 |
|---|---|---|
| DNS 解析不受 800ms 预算约束 | 慢 DNS 名称额外等待 | IP 字面量（10.0.2.2）不受影响；后续可线程化解析 |
| 握手 >800ms 的正常 provider 会被误判不可达 | 弱网误回退 stub | 常量可调；当前为提速取舍 |
| 预探会建立并立即关闭一次 TCP 连接 | provider 侧一条未完成连接日志 | https 不验 TLS；无请求内容 |

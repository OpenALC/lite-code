# v0.6.1-preview.41

> 编辑器面包屑可点击：按目录浏览、下钻或直接打开文件。

## 新增

- 面包屑路径段改为按钮，点击弹出目录内容菜单：
  - 点击目录段：列出该目录；
  - 点击文件名段：列出所在目录。
- 菜单目录优先、同级按名称排序；点击目录下钻，点击文件打开或激活已有标签。
- 菜单固定定位并夹在窗口内；点击外部、Escape、滚动或窗口缩放关闭。
- 仍最多展示路径末 5 段，悬停显示完整路径；定位请求使用工作区根校验。

## 验证

- Web：lint / typecheck / `pnpm test`（405 项 / 28 文件）/ build 全绿。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev，lite-code 工作区）：
  - 面包屑 `lite-code › apps › web › dist › index.html`；
  - 点击 `index.html` 弹出 `assets | favicon.png | index.html`；
  - 点击 `assets` 下钻，列出 `abap-*.js` 等产物；
  - Escape 关闭菜单，切回 tangshan 工作区。

## 已知限制

- 点击文件名列出父目录内容，不是 VSC 的「同级文件」选择器语义。
- 菜单暂不支持方向键导航。
- 目录下钻不改变文件树根，仅用于选择文件。
- 跨工作区标签在面包屑中会因根校验报「path outside project root」。

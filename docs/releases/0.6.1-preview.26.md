# v0.6.1-preview.26

> 编辑器标签补齐 VS Code 手感：拖拽排序、Ctrl+Shift+T 恢复、中键关闭与溢出滚动；
> Agent 代码块支持一键复制。

## 新增

- **Agent 代码块复制**：围栏代码块显示语言标签与「复制」按钮，点击后按钮短暂显示「已复制」；
  复制走 `execCommand`，不触发 WebView2 原生剪贴板权限条。
- **标签拖拽排序**：拖动编辑器标签到目标标签左/右半区，显示插入位置竖线并即时调整顺序；
  顺序随 `lite-code.tabs.v1` 持久化。
- **Ctrl+Shift+T**：重新打开最近关闭的编辑器，LIFO 栈最多 10 个；按关闭时的原位置插入，
  恢复内容、dirty 状态与编辑器策略。命令面板同步新增「重新打开已关闭的编辑器」。
- **中键关闭标签**：与 VS Code 一致；dirty 标签仍先进入二次确认态。
- **标签栏溢出**：标签较多时出现横向滚动，鼠标滚轮在标签栏上直接横向滚动，滚动条隐藏。

## 说明

- 「重新打开」栈只存在内存中，重启应用后清空。
- 文件被删除导致的标签关闭不进入重开栈，避免恢复已不存在的文件。
- 拖拽排序与重开位置只作用于编辑器标签栏；侧栏「已打开编辑器」列表顺序跟随标签顺序。

## 验证

- Web：lint / typecheck / `pnpm test`（388 项 / 26 文件）/ build 全绿；
  markdown 新增复制按钮与本地化文案 1 项、tabs 新增拖拽 3 项与重开 4 项。
- Rust 无变更，沿用 607 项基线。
- 真机（Windows Tauri dev）：
  - 注入代码块后点击复制，拦截 `execCommand` 得到的文本与代码内容完全一致，按钮变为「已复制」；
  - 拖拽 `main.rs` 到 `index.html` 右侧顺序即时变化；
  - 中键关闭 `index.html` 后 Ctrl+Shift+T 在原位恢复；
  - 编辑模式下将标签栏压到 320px，滚轮使 `scrollLeft` 从 0 变为 120。

## 已知限制

- 标签拖拽只支持同栏排序，不支持拖出窗口或拆分标签组。
- 重开栈不持久化；关闭 10 个以上标签后最早的记录被淘汰。

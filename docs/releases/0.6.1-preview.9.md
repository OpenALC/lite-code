# v0.6.1-preview.9

> 预览版：供应商管理页。左侧活动栏的 Agent 入口改为「供应商」，可管理本机
> `~/.lite-code/providers.json`；运行时支持 OpenAI Responses，Anthropic Messages
> 作为协议选项保留但传输层尚未实现。

## 新增

- **供应商管理页**（左侧活动栏「供应商」/ `Ctrl+P` → 供应商）：
  - 供应商：名称、协议格式、Base URL、API Key、启用开关。
  - 模型列表：供应商、模型名称、模型 ID、上下文窗口（K）、压缩阈值（K）、思考强度
    （逗号分隔，如 `off, low, high`）。
  - 默认模型/默认思考强度、Subagent 模型/Subagent 思考强度。
  - 浏览器 dev 模式提供演示数据与明确 fallback 提示，不写入磁盘。
- **API Key 管理**：供应商页可直接填写；保存时空白表示保留旧值，支持显式清除。
  读取时只返回 `hasApiKey` 与末四位提示，完整密钥不回传前端。
- **本地密钥存储**：`providers.json` 原子写入 + `.bak` 备份；Unix 下文件与备份权限
  收紧到 0600。运行时优先级：`LC_API_KEY` 环境变量 > `apiKey` > `apiKeyRef`。
- **配置校验**：provider/model 重复、空字段、Base URL 协议、模型引用、上下文/压缩阈值、
  default/subagent 模型引用均在 Rust 侧校验，错误通过供应商页展示。
- **入口整合**：Agent 空态与设置页新增「供应商管理」按钮；活动栏 Agent 入口改为供应商，
  Agent 仍保留在右侧功能栏。

## 已知问题

1. 供应商页的 API Key 当前以本机明文写入 `providers.json`（Unix 0600）；SecretStore
   接入后会迁移，Windows 依赖用户目录 ACL。
2. Anthropic Messages 仅保留协议选项与配置字段，运行时仍 fail-closed；后续版本接入传输层。
3. Subagent 模型/思考强度目前仅持久化，尚未被 subagent lane 消费。
4. PostgreSQL / MySQL / SQL Server 驱动仍未做真实服务器端到端。
5. Windows 安装包未签名；更新器清单 `signed:false`。

# v0.6.1-preview.14

> Agent 面板按 `demo/index.html` 重做：会话头 + 消息流 + 一体化 composer，AI 消息渲染 Markdown。

## 界面

- **会话头**：`AGENT` 标题、运行状态点、会话名（首条用户消息）、轮次、停止与新会话图标。
- **消息流**：用户消息右对齐气泡；助手消息无边框正文；思考过程折叠展示。
- **工具卡**：工具图标 + 名称 + 单行摘要 + 状态 + 展开箭头；正文默认 5 行并做渐隐，
  展开后完整显示。
- **审批卡**：强调色描边卡片，工具名/命令/来源与理由；按钮右对齐（拒绝 / 本会话同类 / 仅本次）。
- **压缩记录**：单行摘要 + token 变化，可展开摘要正文。
- **一体化 composer**：输入框与模式/模型/思考 pill 同卡片；模型菜单显示供应商与上下文窗口；
  附件 chips 与回形针计数；图标发送按钮。
- **上下文条**：输入框下方 3px 进度条 + 压缩阈值刻度 + `已用 / 预算` 与阈值文案。
- **Markdown**：助手消息支持标题、列表、行内代码、加粗与围栏代码块；渲染前先转义全文，
  只插入固定标签，避免模型输出注入 HTML。

## 行为

- 模式/模型/思考选择改为 composer 内 popover；会话建立后模型与思考锁定，标题提示“新会话生效”。

- 深色/浅色主题均使用现有 tokens，无硬编码颜色。

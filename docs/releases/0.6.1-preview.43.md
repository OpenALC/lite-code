# v0.6.1-preview.43

> 工作区搜索支持「替换全部」：两步确认、显示文件数、跳过 dirty 标签。

## 新增

- 搜索框新增替换开关，展开替换输入框与「替换全部」按钮。
- **两步确认**：第一次点击变为「确认替换 N 个文件」，5 秒内再次点击才执行；
  超出时间自动取消。
- 按当前搜索选项替换：
  - 区分大小写/正则沿用搜索开关；
  - 普通模式把替换文本按字面处理，正则模式支持 `$1` 分组；
- 逐个读取命中文件并写回；已有未保存更改的标签、读取或写入失败的文件会跳过并在结果中提示。
- 非 dirty 的已打开标签同步更新内容并标记为已保存；完成后自动重跑搜索。
- 完成提示：「已替换 X 个文件中的 Y 处」及跳过数量。

## 验证

- Web：lint / typecheck / `pnpm test`（405 项 / 28 文件）/ build 全绿。
- Rust 无变更，沿用 608 项基线。
- 隔离沙箱（`D:/code/lc-replace-sandbox/note.txt`，内容 `alpha beta alpha`）：

  - 首次点击显示「确认替换 1 个文件」，再次点击后提示「已替换 1 个文件中的 2 处」；

  已逐文件反向恢复并核对计数（6/17/5 处全部还原）。

## 已知限制

- 替换范围是搜索命中的文件，替换时按整文件全部匹配执行（不受 500 条展示上限限制）。
- 不支持单条命中替换、撤销堆栈或替换预览 diff。
- dirty 标签直接跳过；关闭标签后可重新搜索替换。
- 未做编码检测，按 UTF-8 读写；非 UTF-8 文件可能损坏，请谨慎使用。

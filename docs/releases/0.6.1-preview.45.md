# v0.6.1-preview.45

> 设置页按 Kimi Code Desktop 风格重构；设置/搜索等 UI 图标换成 Kimi 风格；设置页独占编辑器宽度。

## 变更

- 设置页重构：左侧 184px 分区导航（通用 / 编辑器 / Agent / 快捷键 / 关于，均带图标），
  右侧分组卡片使用 16px 圆角、52px 行高与 hairline 分隔；≤760px 时导航转为横向滚动。
- 设置页获得完整编辑器宽度：打开时自动收起右侧功能栏与底部面板；行标签使用 flex 基准宽度，
  窄容器下不再逐字竖排。
- UI 图标：设置、搜索、Agent、快捷键、关于 换为 Kimi Code Desktop 的 24×24、
  `stroke-width: 1.8` 风格路径；应用 Logo 保持原有 Lite Code 蓝色圆角图标不变。
- 维护：用圆角透明母版重新生成 macOS `icon.icns`。

## 验证

- Web：lint / typecheck / `pnpm test`（408 项 / 28 文件）/ build 全绿；本次为样式与图标改动，无新增测试。
- Rust：无逻辑变更，沿用 608 项基线。
- 真机（Windows Tauri dev，1280×800）：设置页卡片宽 708px，四行设置项横向排列；
  快捷键 10 行文字与 `kbd` 均单行；左导航 5 项图标正常；打开设置时右栏与底部面板自动收起。

## 已知限制

- 本轮仅替换设置、搜索、Agent、快捷键、关于 5 个图标，其余图标仍为现有线性图标。
- 设置页打开会收起右栏/底部面板，关闭设置后不自动恢复。

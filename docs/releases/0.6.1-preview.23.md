# v0.6.1-preview.23

> 消息级分叉：编辑历史用户消息或从某轮之前重试，原会话保留。

## 新增

- 用户消息悬停「编辑并分叉」：
  - 截断该消息之前的会话上下文，载入为只读历史视图；
  - 把该条用户消息恢复进 composer，可编辑后发送；
  - 发送时由现有控制器新建会话，并注入截断后的最近上下文。
- 助手消息悬停「分叉重试」：找到该轮对应的用户消息，分叉后立即重发。
- 分叉快照会清理工具卡、审批、压缩记录与 usage，只保留消息与对应轮次的 turnStats；
  原会话与历史文件不受影响。
- 流式运行中或审批挂起时隐藏分叉操作，避免与当前轮交叉。

## 参考

- Kimi Code Desktop 的消息编辑/重试交互；本实现用「分叉」语义，不修改原会话。

## 验证

- Web：lint / typecheck / `pnpm test`（376 项 / 25 文件）/ build 全绿；
  新增 forkSession 3 项（截断/首条空上下文/非法消息）。
- Rust 无变更，沿用 607 项基线。
- 真机（Windows Tauri dev）：
  - 完成一轮后用户消息出现「编辑并分叉」，点击后草稿恢复为原文、消息流切到分叉历史；
  - 首条消息分叉得到空上下文，符合“从该消息前开始”的语义。
  - 重试按钮与编辑共用同一分叉路径；未在真机触发额外 API 调用。

## 已知限制

- 是“分叉”而非原地回滚：原会话保留，新对话会出现在历史列表。
- 附件内容无法从消息文本重建；分叉只恢复文字。
- 没有分支树/父子对话可视化；工具调用记录不参与分叉上下文。

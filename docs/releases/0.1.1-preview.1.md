# v0.1.1-preview.1

> P1（编辑器 alpha）里程碑包：Windows 可安装，Linux 仅构建验证。
> 未安装 Node 的机器上，编辑器、文件树与保存可用；Node 相关功能显示降级引导。

## 新增

- 文件树：`ignore` 遍历、按层加载、根内路径校验、文件变更监听骨架。
- Monaco 编辑器：打开真实文件、标签页、每标签独立 model（undo/光标/滚动保留）、窗口级 Ctrl+S 保存。
- 大文件分级：<5MB 完整能力；5–20MB 关闭 occurrences/折叠/minimap；>20MB 只读预览。
- 保存安全：临时文件 + fsync + rename，保留原权限；拒绝根外路径与悬空软链。
- dirty 跟踪：以 `savedContent` 为基线，撤销回已保存内容自动变干净。
- Runtime 设置页：Node 探测、候选失败原因、手动路径校验、便携版下载、降级提示。
- 布局：侧栏 / Agent / 底部面板可拖拽、可折叠，本地持久化。
- 契约 v0.1：`workspace_root`、`fs_write_file`，TS 绑定改为可直接 import 的 ES 模块。
- CI：Windows/Ubuntu 测试矩阵、lane 边界、cargo-deny、契约漂移、web 四件套。
- `lc-cli`：`node detect` / `node set-manual` / `node portable download` / `node info` / `shell detect` / `contract info`。

## 已知问题

1. 安装包未签名，首次运行 SmartScreen 可能提示“未知发布者”，属预期行为。
2. workspace 根仍取启动 CWD 或 `LC_WORKSPACE_ROOT`，尚无“打开文件夹”流程。
3. 保存没有外部修改冲突检测（已有 savedContent 基线，尚未加 mtime/hash）。
4. 托盘“退出”不会提示未保存缓冲区。
5. >20MB 文件仍整文件读入后只读预览；后续改为截断/原始字节传输。
6. Linux 产物仅构建验证，P2 起提供正式 AppImage/deb 发布。

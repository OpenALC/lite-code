# v0.6.1-preview.21

> composer 支持 `@` 引用工作区文件：按需索引、键盘选择、插入相对路径。

## 新增

- 在 Agent composer 输入 `@` 打开文件引用浮层：
  - 首次打开时按需遍历当前工作区（深度 ≤6、最多 2000 个文件），缓存到该工作区。
  - 跳过 `.git/.zcode/.claude/.playwright-mcp` 等隐藏工具目录，以及
    `node_modules/target/dist/build/coverage/vendor/.venv` 等大目录。
  - 输入 `@read` 之类的片段即时过滤；文件名前缀优先，其次文件名包含，最后路径包含。
  - ↑/↓ 选择、Enter 插入、Esc 关闭；点击插入。
  - 插入形式为 `@相对路径 `，Agent 可用现有 read_file 工具读取，不额外内联文件内容。
- 索引超过 2000 个文件时提示截断；无工作区时提示先打开工作区。

## 已知限制

- 索引是应用侧自定义跳过列表，不等同 `.gitignore`；超大 monorepo 可能截断。
- 索引按工作区缓存，新建文件需重新加载窗口或切换工作区后才会出现。
- 引用只插入路径，不自动附带文件内容；文件内容由 Agent 工具读取。

# v0.6.1-preview.42

> 文件树支持键入首字母快速定位，配合方向键导航。

## 新增

- 文件树聚焦时直接键入字母/数字：累积为前缀并跳转到下一个匹配项（大小写不敏感、
  `startsWith` 匹配），从当前项之后开始并循环。
- 前缀缓冲 600ms 后自动清空；空格、Ctrl/Alt/Meta 组合键不参与。
- 切换工作区、刷新文件树或卸载组件时清空缓冲与计时器。

## 验证

- Web：lint / typecheck / `pnpm test`（405 项 / 28 文件）/ build 全绿。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev，tangshan 工作区）：
  - 聚焦 `.claude` 后连续输入 `app`，焦点跳到 `D:\code\tangshan\app`；
  - 方向键/展开/折叠行为不受影响。

## 已知限制

- 只匹配当前可见行的名称前缀，不搜索未展开目录内容。
- 不做拼音/模糊匹配，不支持中文 IME 组词输入。
- 600ms 内连续输入会累积为同一前缀，停顿后重新开始。

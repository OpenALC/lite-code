# v0.6.1-preview.38

> Agent composer 支持拖拽文本文件为附件，限制与文件选择器一致。

## 新增

- **拖拽添加附件**：把文件拖到 composer 上出现虚线蓝框提示，松开后按文本读取为附件。
- **限制对齐原生选择器**：单文件 ≤256 KiB、最多 10 个、总量 ≤1 MiB；
  超限显示对应错误并跳过。
- **文本校验**：包含 NUL 的文件按二进制跳过；读取失败显示文件名。
- 拖到 composer 之外时阻止 WebView2 直接打开文件，避免应用被替换成文件内容。
- 附件去重按文件名；同名文件以最后一次拖入为准。

## 验证

- Web：lint / typecheck / `pnpm test`（404 项 / 28 文件）/ build 全绿。
- Rust 无变更，沿用 608 项基线。
- 真机（Windows Tauri dev）：
  - 拖入 `note.txt` 时显示「松开以添加文本附件」，松开后 composer 出现 `note.txt` 附件；
  - 拖入 300 KiB 的 `big.txt`，提示「big.txt 超过 256 KiB，已跳过」；
  - 刷新后测试附件清除。

## 已知限制

- 只接受 UTF-8 文本；图片/PDF/二进制不会上传。
- 拖拽项使用文件名作为路径，不含原始目录；同名文件会覆盖。
- 浏览器演示模式不启用附件（与原生选择器一致）。

# v0.2.1-preview.1

> P2（首个 pre-release）：第一个面向外部下载的编辑器 alpha 版本。
> Windows 提供 NSIS 安装包，Linux 提供 AppImage / deb；安装包未签名。

## 主要能力

- **编辑器**：文件树按层加载、Monaco 打开真实文件、标签页、每标签独立 undo/光标、窗口级 Ctrl+S 保存。
- **保存安全**：临时文件 + fsync + rename，保留权限；拒绝根外路径与悬空软链；dirty 以 `savedContent` 为基线。
- **大文件**：<5MB 完整；5–20MB 关闭 occurrences/折叠/minimap；>20MB 只读预览。
- **运行时**：Node 探测、手动指定、便携版下载、候选失败原因与降级引导。
- **工作区**：顶栏打开目录，根由 Rust 持有并持久化；关闭窗口销毁 WebView，托盘/二次启动重建并恢复标签。
- **布局**：侧栏 / Agent / 底部面板可拖拽、可折叠，偏好本地持久化。
- **CLI**：`node` / `shell` / `contract` / `fs read-dir`，与契约同形，可用于 headless 回归。

## 安装

- Windows：下载 `Lite.Code_0.2.1-preview.1_x64-setup.exe`。
- Linux：AppImage 或 deb；需要系统 `webkit2gtk-4.1`。
- **未签名**：Windows SmartScreen 可能提示“未知发布者”，属预期行为。
- 发布页附 `SHA256SUMS`。

## 已知问题

1. 安装包未签名，SmartScreen 可能提示未知发布者。
2. 打开工作区目前是路径输入，原生文件夹选择器尚未接入。
3. 保存没有外部修改冲突检测（mtime/hash 未做）；同一文件被外部修改后保存会覆盖。
4. 托盘“退出”不会提示未保存缓冲区。
5. >20MB 文件仍整文件读入后只读预览，尚未改截断/原始字节传输。
6. `activeRssMb` 缺 UI 自动化入口未测；冷/热启动终点是“窗口可见”，不是应用内“可交互”。
7. 干净 Win11 无 Node 的最终人工验收仍待执行；Node 缺失路径已由 core/UI 测试覆盖。

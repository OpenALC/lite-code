# v0.6.1-preview.8

> 预览版：preview.7 的收尾构建。功能面不变，仅补齐搜索截断文案与快速打开键盘焦点行为；
> 作为 preview.7 的重建号发布。

## 修复

- **搜索截断文案**：单个文件命中达到 100 行上限时，界面此前固定显示“仅显示前 500 条”，
  与实际条数不符。现在按 `totalMatches` 显示“结果已截断，仅显示前 N 条”，中英文一致。
- **快速打开 Tab 失焦**：Ctrl+P 输入后按 Tab 离开面板，弹层此前不会关闭；现在
  `focusout` 检测焦点是否仍在 `.quick-wrap` 内，离开即收起并清空查询，结果项之间
  移动焦点不受影响。
- 其余内容与 `v0.6.1-preview.7` 相同：`fs_search` 参数命名与异步执行、设置入口统一、
  搜索侧栏状态保留、定位请求消费、CodeEditor 生命周期修复、结果截断判定、非法正则本地化。

## 验证

- Rust：`cargo fmt --check` / `cargo clippy -D warnings` / `cargo test --workspace --locked`
  全绿；本机 546 项（`fs::search` 14 项、`db_agent` 集成 2 项）。
- Web：lint / typecheck / `pnpm test`（316 项 / 17 文件）/ build 全绿。
- 真机 Tauri/WebView2：单文件 150 条命中显示“前 100 条”；Tab 离开快速打开后弹层关闭；
  大小写开关、Ctrl+, 设置、搜索跨视图保留、原生选择器、右键、拖拽、主题/缩放正常。
- `scripts/check-lanes.sh` 通过。

## 已知问题

1. PostgreSQL / MySQL / SQL Server 驱动已打包，但本机无真实服务器；仅验证驱动加载、
   参数映射与失败路径，未做端到端查询。
2. 搜索每行只返回首个匹配，单次最多 500 行；不支持替换与搜索历史。
3. Windows 安装包未签名；更新器清单 `signed:false`。
4. Linux arm64 使用 Ubuntu 24.04 基线，22.04 arm64 兼容性未验证。
5. 鸿蒙首版仍不提供可编辑 Monaco（只读预览 + 对话）。
6. MCP 仅 stdio；项目 `.mcp.json` 需 `LC_MCP_ALLOW_PROJECT=1` 显式开启。

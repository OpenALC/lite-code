# v0.6.1-preview.5

> 预览版：UI 打磨 + 工作区全文搜索。基于 `v0.6.1-preview.4`（VS Code 式外壳与多数据库驱动）。
> A 类门禁已在 CI 覆盖；B 类外部项（签名、30 天 soak、第三方审计、Win11 验收）仍由维护者关闭。

## 新增

- **工作区全文搜索**：Rust `fs_search` 命令与 `SearchView` 侧栏。
  - 字面量 / 正则、区分大小写开关，尊重 `.gitignore` / `.ignore`。
  - 跳过二进制与 >2 MiB 文件，单文件 100 行、总计 500 行上限。
  - 结果按文件分组、命中高亮、显示行号；点击直接打开文件并定位到命中行。
  - 顶部快速打开（Ctrl+P）在无匹配时提供“在文件中搜索”入口。
- **设置页**：作为编辑器区独立页签打开（VS Code 行为），支持主题、语言、页面缩放、
  编辑器字号（11–20）、Tab 宽度（2/4/8）、自动换行；全部实时应用并持久化。
- **设置页版本号**：由 Vite 从 `apps/web/package.json` 注入，不再硬编码。
- **编辑器 minimap**：改为块状渲染、限制列数、滑块仅在悬停时显示，减少视觉噪声。

## 修复

- 中文界面残留英文：无工作区时的 “WORKSPACE”、数据库路径提示、Agent 供应商/API 密钥文案。
- 右侧 Agent 面板在 280–400px 宽度下“轮次”被裁切。
- 标题栏语言按钮点击无效（此前只是重新应用当前语言）。
- 文件树“刷新”按钮错误触发“打开工作区”弹窗；现在会丢弃层级缓存并重新读取根目录。
- 状态栏分支名重复显示为 “main main”。
- 侧栏项目名强制大写、与文件树标题重复。

  本机 541 项（含 `fs::search` 9 项、`db_agent` 集成 2 项）。
- Web：`pnpm lint`、`pnpm typecheck`、`pnpm test`（315 项 / 17 文件）、`pnpm build` 全绿。
- 真机 Tauri/WebView2（Windows 11）逐项验证：
  原生文件夹选择器、全文搜索与命中跳转、文件树/编辑器右键菜单、拖拽移动文件、
  主题/语言/缩放切换、设置页、Git/数据库右栏不遮挡编辑器。
- `scripts/check-lanes.sh` 通过。

## 已知问题

1. PostgreSQL / MySQL / SQL Server 驱动已打包，但本机无真实服务器；仅验证驱动加载、
   参数映射与失败路径，未做端到端查询。
2. 搜索每行只返回首个匹配，单次最多 500 行；不支持替换与搜索历史。
3. Windows 安装包未签名，SmartScreen 可能提示未知发布者；更新器清单 `signed:false`。
4. Linux arm64 使用 Ubuntu 24.04 基线，22.04 arm64 兼容性未验证。
5. 鸿蒙首版仍不提供可编辑 Monaco（只读预览 + 对话）。
6. MCP 仅 stdio；项目 `.mcp.json` 需 `LC_MCP_ALLOW_PROJECT=1` 显式开启。
